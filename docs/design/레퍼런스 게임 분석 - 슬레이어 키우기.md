# 레퍼런스 게임 분석 — 슬레이어 키우기 (GEAR2)

> 작성 2026-06-05. 우리 "복권 키우기 : Idle RPG"의 **레퍼런스 게임**으로 채택, 시스템 학습본.
> ⚠️ 출처 한계: 나무위키 본문이 직접 fetch 차단(403) → 나무위키/공략 **검색 요약 + 일부 블로그**로
> 삼각측량했다. 세부 수치(레벨 상한·확률 등)는 근사이며 버전(대략 r616 시기)에 따라 다를 수 있다.
> 목적은 정확한 수치 복제가 아니라 **설계 구조·패턴 학습**.

---

## 1. 한 줄 요약
GEAR2의 모바일 **방치형 헌터 RPG**. 자동 사냥으로 무한 스테이지를 밀며, **여러 재화 × 여러 성장 축
× 수집/융합/등급 차등**으로 깊이를 만들고, **풍부한 리텐션(출석·일일·복귀·정시 지급)**과 광고/패키지로
운영한다. 우리 게임과 장르("키우기" 방치형)·코어(자동 진행+강화 루프)가 같고, **우리에게 없는 "깊이
레이어"를 다수 보유** → 차용 후보의 보고.

## 2. 코어 루프
캐릭터(헌터) 자동 사냥 → 몬스터가 **골드·경험치·속성석·상자** 드롭 → 재화로 **강화/성장/장비/스킬** →
더 센 스테이지 → 반복. 능동 요소는 스킬 사용·콘텐츠 입장 위주(전투 자체는 방치). **우리와 동일한 골격**
(우리는 그 위에 "스크래치로 공격"이라는 능동 throughput 레이어가 추가된 형태).

## 3. 재화 체계 (멀티 커런시) — 우리와 가장 다른 지점
| 재화 | 주 용도 | 비고 |
|---|---|---|
| **골드** | **강화**(공격력/체력/회복 등 스탯) | 몬스터 드롭, 기본 sink |
| **SP** | **성장**(레벨업 시 지급 → 스탯에 투자) | "훈련 일지"로 맥스레벨 확장 |
| **다이아** | 무기 **뽑기** 주재화 | 정시 지급(매일 18시 1000, 21시 5000) + 일일/이벤트 |
| **에메랄드** | **스킬 개방** | 일일 퀘스트 등 |
| **깃털** | 던전 **추가 입장** | 출석·일일 퀘스트 |
| 속성석 / 무기강화석 | 속성·무기 강화 재료 | 스테이지 드롭 |
| 다이스·용의 힘·마나결정 | (상위/특수 콘텐츠 재화) | 상자 드롭에서 제외되는 귀한 재화 |

➡️ **인사이트**: 재화를 쪼개 **각 성장 축을 별도 재화로 게이팅**한다(골드=강화, SP=레벨, 다이아=뽑기,
에메랄드=스킬). 한 재화가 모든 걸 사면 의사결정이 사라지는데, 분리하면 "오늘 뭐에 쓸까"가 매일 생긴다.
**우리는 "단일 골드"를 의도적으로 고수**(컨셉 결정) — 단순함이 강점이지만, **전투로만 얻는 비-골드 축**
(아래 승급)이나 **시간 지급 재화**(정시 다이아)는 단일 골드 원칙을 깨지 않고도 참고할 여지가 있다.

## 4. 성장 4축 — ⭐ 핵심 학습 포인트
슬레이어의 깊이는 "강화 트랙 많음"이 아니라 **성격이 다른 성장 축 4개의 중첩**에서 온다:

1. **강화 (골드)** — 공격력·체력·체력회복 등 스탯을 골드로 직접 올림. **우리 강화 트랙과 동일 성격**(반복 도파민, 곡선=비용 지수↑).
2. **성장 (SP)** — 레벨업마다 받는 SP를 투자. 골드와 **별도 페이싱**(전투 시간에 비례) + "훈련 일지"로 상한 확장. ➡️ *우리 캐릭터 레벨 개념이 약함 → SP식 "전투량 비례 포인트" 축은 신선한 차용 후보.*
3. **승급 (전투로 획득)** — 일정 도달 시 **"굉장히 큰 폭"으로 성장** + **코스튬**(미스릴~) 해금(코스튬마다 효과·획득법 다름). ➡️ *우리 **보스/블록 클리어**와 직결 — "블록 돌파 = 승급 보상(큰 점프 + 코스튬/외형)"으로 매핑하면 보스 게이트에 보상 동기가 생긴다.*
4. **환생 (리셋)** — 기본 리셋 / 고급 리셋. 캐릭터 **1000레벨 이후 고급 리셋에 필터+자동 리셋**. ➡️ *우리 **환생은 현재 보류** 결정이지만, "자동 리셋(필터)"은 방치형 후반 편의의 정석 — 도입 시 참고.*

➡️ **메타 인사이트**: 축마다 **페이싱 소스가 다르다**(골드=드롭, SP=레벨, 승급=클리어, 환생=장기 반복).
이게 "할 게 항상 하나는 더 있다"를 만든다. 우리는 현재 **강화 1축에 거의 의존** → 적어도 "**클리어로만
오르는 축**(승급형)" 하나를 더하면 보스 게이트가 보상 루프가 된다.

## 5. 수집·융합·등급 차등 (장비/정령/유물/스킬)
- **무기/악세서리**: 같은 것 **5개 융합 → 다음 등급**. 등급 **일반→고급→레어→영웅→전설→신화→불멸**. 뽑기 반복 시 "소환 레벨"이 올라 상위 등급 확률↑.
  - **등급별 효과 "차등 해금"** (중요한 디자인): 무기 — 일반~고급=데미지만 / 레어~전설=+치명타 데미지 / 신화~불멸=+골드 획득량. 악세 — 일~고=체력·회복 / 레어~전설=+마나회복 / 신화~불멸=+경험치. ➡️ *상위 등급이 단순히 "수치 ↑"가 아니라 **새 효과 종류를 연다** → 등급업의 질적 보상.*
- **정령(펫) 12종**: 같은 정령 **4마리 융합 → 진화**, 12종 전부 신화 달성 시 **각성 → 불멸**. (장기 컬렉션 목표)
- **유물**: 융합 불가, **같은 유물 1개로 강화**, 등급 없음. 강화 성공 **확률 점감**(100%→99.3%→1.7%씩↓→54레벨부터 10% 고정). ➡️ *확률 기반 도박형 강화 = 장기 sink + 스릴.*
- **스킬(카드)**: 소환/융합으로 획득, **레벨↑ → 숙련도↑ → 전(全) 속성 데미지↑**. 사냥/보스/모험용 스킬을 칸에 배치(상황별 빌드). 동일 등급 내 획득 확률 균등.

➡️ **인사이트**: "**같은 것 N개 → 합쳐서 한 단계 위**"(5합/4합)가 모든 컬렉션의 공통 동사. 우리 **복권
등급**(확장 예정)에 이 패턴이 자연스럽다 — *낮은 등급 복권 N장 → 상위 등급 복권*, 등급↑마다 **새 효과
해금**(예: 일반=배율만 / 레어=+잭팟확률 / 신화=+골드).

## 6. 콘텐츠 모드 (반복 일일 던전 + 길드)
| 모드 | 입장 조건 | 보상/특징 |
|---|---|---|
| **용의 협곡** | 265레벨, **하루 3회 무료** | 드래곤 보스 1마리 단판 |
| **폐광** | 280레벨 | 보스 타격으로 **무기 강화석** |
| **순환의 숲** | 100스테이지 클리어, **하루 3회**(+깃털로 추가) | 재료 파밍 |
| **길드** | — | 사회적 콘텐츠(모험/길드) |

➡️ **인사이트**: **"하루 N회 입장" 일일 던전**이 리텐션의 척추. 각 던전이 **특정 재화를 독점 공급**
(폐광=강화석)해 "매일 들어올 이유"를 만든다. + 깃털로 **추가 입장 과금/소비** 여지. ➡️ *우리도 리텐션
단계에서 "**일일 특수 스테이지**(N회, 특정 보상 독점)"를 고려할 가치 — 우리 무한 스테이지 본류와 분리된
짧은 반복 루프.*

## 7. 리텐션 구조 — ⭐ 우리 다음 작업과 직결
- **출석체크** + **일일 퀘스트**: 다이아·깃털·에메랄드 지급. **반복 가능 미션**(같은 조건 여러 번 완료, 보상 중첩) → "더 하면 더 받음".
- **정시 지급**: 매일 **18시 1000 / 21시 5000 다이아** → **특정 시간 접속 유도**(앱 오픈 습관화).
- **복귀 유저 출석**: 15일·30일 미접 후 복귀 시 보상, **1회 한정 아님(여러 번)** → 이탈자 회수 루프.
- **패키지/스테이지 패키지**: 20스테이지마다 패키지 공개(진행 연동 과금 트리거).
- **광고**: 광고 소환 / 광고 골드 / 광고 제거 패키지.

➡️ **우리 리텐션 기획(`리텐션 시스템 정리본.md`)과 대조**:
- 우리 기획에 있는 것: 출석/퀘스트/업적, 수령식(claim), 보상=`Balance.reward_gold`(스테이지 스케일).
- **슬레이어에서 추가로 배울 것**: ①**반복 가능 일일 미션**(중첩 보상)로 "상한 없는 능동 보상", ②**정시 지급**으로 접속 습관화(우리 kplay/웹 환경에 맞게 변형), ③**복귀 출석**(이탈 회수, 여러 번), ④보상을 **스테이지 골드뿐 아니라 "특정 축 전용 재화"로** 줘서 성장 의사결정 유발(단일 골드 원칙과 충돌 시 조정 필요).

## 8. 수익화 (참고)
무기 뽑기(다이아), 광고 제거/광고 보상, 한정·스테이지 패키지. 직접적 P2W보다 **편의·가속·확률**(뽑기) 중심.
우리는 kplay 플랫폼이라 수익화 모델은 별도지만, **"광고 보상"(소환/골드 가속)**은 웹에서도 흔한 패턴.

## 9. 우리 "복권 키우기"에 적용 — 우선순위 정리
바로 쓸 것 / 중기 / 보류로 분류:

**A. 지금(리텐션 작업)에 직접 반영**
- **반복 가능 일일 미션 + 중첩 보상** (능동 보상 상한 제거)
- **복귀 유저 출석**(여러 번 수령) — 이탈 회수
- (검토) **정시/시간대 보상**을 웹·kplay 맥락에 맞게 — 우리 오프라인 정산과 충돌 안 하게 설계

**B. 중기 — 성장 깊이 (강화 1축 탈피)**
- **승급형 축**: **블록(10) 돌파 = 큰 점프 + 코스튬/외형 보상** → 보스 게이트에 당근. (현재 보스는 위협만, 보상 약함)
- **복권 등급 + 융합 + 등급별 효과 차등**: 낮은 등급 N장 합성 → 상위 등급, 등급↑마다 **새 효과 해금**(배율→+잭팟확률→+골드). 우리 "스크래치 분포/등급" 다음 작업과 정확히 연결.
- **확률형 강화(유물식)**: 성공 확률 점감하는 장기 sink 1종(스릴).

**C. 보류 — 컨셉 결정과 상충/대형**
- **멀티 커런시**: 우리는 단일 골드 고수 → 전면 도입 X. 단, "**전투로만 얻는 비-골드 포인트**"(승급/특정 던전 전용) 정도는 단순성 해치지 않는 선에서 검토.
- **환생/프레스티지**: 이미 "보류" 결정. 도입 시 **자동 리셋(필터)** 패턴 참고.
- **펫/스킬 카드/길드**: 범위 큼. 현재 단계 과함.

➡️ **핵심 교훈 한 줄**: 슬레이어의 리텐션·깊이는 "**페이싱 소스가 다른 축의 중첩 + 같은것N개→상위
등급(새 효과 해금) + 매일 들어올 독점 보상 루프**"에서 나온다. 우리는 **단순함(단일 골드·스크래치)**을
지키되, 그 위에 **(1) 보스/블록을 보상 루프로(승급) + (2) 복권 등급 융합(차등 효과) + (3) 반복/복귀
리텐션** 셋을 얹는 게 가성비 최선.
