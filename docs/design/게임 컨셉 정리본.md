# 게임 컨셉 정리본

> 게임의 최상위 컨셉 기준 문서. 세부 메커니즘은 [[전투 시스템 정리본]] · [[스크래치 시스템 정리본]], 백엔드는 [[백엔드 시스템 정리본]], 밸런스 방향은 [[밸런스 초안]] 참조.

## 1. 한 줄 요약

자동으로 긁히는 복권으로 싸우는 횡스크롤 방치형. 골드로 **복권과 캐릭터를 키워** 무한 스테이지를 밀고 나간다. 안 만져도 자동으로 진행되지만, 직접 긁으면 훨씬 빠르다. 일반 스테이지는 항상 클리어되고, **10단위 보스에서만 사망 위험**이 있다(사망 시 몇 스테이지 소폭 후퇴).

## 2. 장르

- **복권을 키우는 방치형(idle).** 스크래치가 핵심 입력이며, 일반 스테이지는 실패 없이 성장으로 진행하되 **10단위 보스가 성장 게이트**(사망 가능)로 작동한다.
- 성장의 메인 대상은 **복권 그 자체** (캐릭터/무기 대신 복권을 키운다 — 테마 일관).
- 무게중심은 **능동 중심, 방치는 보조**(이탈 방지·따라잡기). 방치로도 성장은 꾸준히 된다.
- 디바이스/플랫폼: 모바일 세로(360×780), HTML5 브라우저.

## 3. 코어 루프

```
[① 일반 공격(자동)] 교전 중 고정 주기(Balance.AUTO_ATK_SPEED)마다 자동 발동 → 바닥 DPS
[② 스크래치 스킬(버스트)] 복권이 항상 긁히는 중 (방치=느림 / 능동=손가락 속도로 폭증)
  → 9칸 전부 공개 → 족보 평가 → 강한 한 방 발사
  → 적에게 데미지 → 적 처치 → 골드 획득
  → 캐릭터 / 복권 / 저장소 업그레이드 → 더 강해짐
  → 더 센 적(다음 스테이지) → 더 많은 골드 → 반복
```

전투는 두 레이어로 진행된다 — **①일반 공격(자동)**: 교전 중 고정 주기(Balance.AUTO_ATK_SPEED = balance.auto_attack.speed)마다 자동 발동, 데미지 = 캐릭터 공격력 × 기본계수(AUTO_ATK_COEF). 데드타임을 없애는 바닥 DPS다. **②스크래치 스킬(버스트)**: 9칸 완성 시 발사, 데미지 = 캐릭터 공격력 × 복권 배율 × 족보배율. "이번 한 방"의 천장이다. 스크래치는 유일한 공격이 아니라 항상 들어가는 자동 일반공격 위에 얹히는 버스트 스킬이다.

캐릭터가 우측으로 진행하는 횡스크롤 위에서 전투가 벌어진다(캐릭터·적·이펙트).

## 4. 스크래치 (자동/능동 통합)

- 복권 한 장은 **항상 긁히고 있다.**
  - **자동(방치)**: 입력이 없어도 느린 속도로 한 칸씩 자동 공개.
  - **능동**: 직접 드래그하면 손가락 속도만큼 훨씬 빠르게 공개.
- **운(족보)은 누가 긁든 동일** — 능동은 "분당 복권 수 = 공격 횟수(throughput)"만 폭증시킨다. 능동을 많이 할수록 잭팟 기회도 늘어난다.
- 그리드는 **3×3 고정** (확장 보류). 세부는 [[스크래치 시스템 정리본]].

## 5. 전투력 (곱연산)

```
스크래치 스킬 버스트  ≈  캐릭터 기본 공격력(베이스)  ×  복권 족보배율(폭발·운)
```

(위 곱연산 공식은 **스크래치 스킬 버스트** 기준. 그와 별개로 교전 중에는 일반 공격(자동)이 항상 바닥 DPS를 깐다 — §3 참조.)

- **캐릭터 = 바닥을 올림** (모든 긁기가 통째로 강해짐).
- **복권 = 천장을 올림** ("이번 한 방"이 얼마나 터지는가).
- 곱연산이라 한쪽만 키우면 효율이 떨어져 **둘 다 키우도록** 유도된다.

## 6. 성장 축

| 축 | 담당 | 성격 | 텀 | 상한 |
|---|---|---|---|---|
| **캐릭터 기본 공격력 + 생존력(HP/방어)** | 베이스 전투력 + 보스전 생존 | 싸고 자주 누르는 반복 도파민 (그라인드 바닥·리텐션) | 짧음 | 사실상 무한 |
| ~~캐릭터 공격속도(attack_speed)~~ **폐지** | 일반 공격(자동) 발동 빈도 → 이제 **고정값**(balance.auto_attack.speed = 3.3, `Balance.AUTO_ATK_SPEED`). 옛 강화 max값을 기본 제공, 자동공격 DPS는 공격력으로만 성장 | — | — | 고정 |
| **복권 배율 / 족보 / 잭팟 / 숫자범위 / 등급** | 폭발력·운 | 가끔 터지는 도박적 쾌감 (천장) | 중간 | — |
| **복권 자동 긁기 속도** | 방치 DPS | 가끔 한계까지 올리는 마일스톤 | 긺 | 있음 |
| **저장소 용량** | 오프라인 누적 상한 확장 | 압박 해소용 투자 | — | — |

- 생존력 축은 두 트랙으로 나뉜다: **hp(최대 체력)** + **hp_regen(체력 재생, 초당 자동회복)** — 별개 트랙이다. hp는 보스 순간딜을 버티는 풀(천장), hp_regen은 블록 내 찔끔 피해 상쇄(유지). 상세는 [[강화 시스템 정리본]].

"막 누르는 맛(캐릭터) / 터지는 맛(복권 운) / 가끔 해방되는 맛(자동 속도)"으로 누르는 결을 분리한다.

### 6-1. 성장 4축 분리 (역할)

위 강화 트랙과 별개로, 게임 전체 성장은 **4개 축**으로 역할을 나눈다.

| 축 | 성격 | 역할 |
|---|---|---|
| **강화** | 골드 무한 스탯 · 수직 · 비가챠 | 그라인드 바닥(위 §6 트랙) |
| **장비** | 능력치 + 다이아 가챠 | **BM 기둥**. 무기(공격력 곱)/방어구(최대HP 곱), 5등급·강화·합성 구현 완료 ([[장비 시스템 정리본]]) |
| **유물** | 장착 슬롯 빌드 재미 · 수평 · 비파워 | 빌드 다양성('스킬' 시스템 대체) |
| **족보** | 매칭 등급 레벨업 | 스크래치 버스트 천장 |

- ⚠️ **유물 ≠ 장비**: 유물 = 빌드 재미(수평·비파워), 장비 = 능력치 + BM 직결.
- **'스킬' 시스템은 미사용** — 그 자리를 유물(슬롯 빌드)이 대체한다.

→ 트랙별 수치·곡선·구매·강화 패널 상세는 **[[강화 시스템 정리본]]**.

## 7. 경제 (재화)

- **주 통화 = 골드** (= 복권 당첨금).
  - 획득원: **적 처치(메인)** + **잭팟/고족보 보너스**(쾌감→경제 연결) + **오프라인 누적**.
  - 쓸 곳 3개(**캐릭터 / 복권 / 저장소**)가 한정 골드를 두고 경쟁 → 이 긴장이 곧 키우는 재미.
- **다이아(임시명)** = 장비 가챠 소비 재화. 가챠 1회 비용 **100**. 현재 획득처 = **퀘스트·우편함 보상**(`quests.gd` 카탈로그 보상 대부분 다이아) + 치트 — 단 **전부 임시 더미 지급**이며 **본격 획득 곡선·밸런스는 미설계**다. ⏸ 정식 정규 획득처(스테이지 드롭 등)·공급량 곡선 미정.
- **유물 가루(dust)** = 유물 가챠/합성 재화(별도 통화). **정식 주 획득처 = 보스 첫 클리어**(2026-06-17 확정·구현 — `Balance.boss_dust(stage)=per_boss_base+per_boss_step×(블록인덱스-1)`, `backend.grant_boss_dust`가 세이브 키 `dust_boss_max`로 첫 클리어만 지급·재파밍 차단). 보조 획득 = 중복 유물 자동 환급 + 퀘스트·우편함 더미. 획득 **메커니즘은 설계·구현됨**(공급량 수치만 더미·밸런스 미튜닝). 상세는 §10 유물 항목 / [[족보 스킬 시스템 정리본]] §5-4.
- 통화 일반화 토대는 구현됨(키 기반 라우팅 — `get/add/spend_currency`, 골드/다이아/가루 별칭 `CUR_GOLD`/`CUR_DIA`/`CUR_DUST`). 재화별 역할·획득처·소비처의 기준은 **[[재화 정책 초안]]**.

## 8. 방치 / 오프라인

- 무게중심은 **능동 중심, 방치는 보조**(안 만져도 굴러가되 만지면 훨씬 빠름).
- 방치를 묶는 상한 2개: **자동 긁기 속도 상한**(시간당 rate) + **오프라인 누적 상한**(금액 기준 = 저장소 업글 압박).
- → 무게중심·두 상한·오프라인 정산 공식·재접속 주기 상세는 **[[오프라인·방치 시스템 정리본]]**.

## 9. 스테이지 / 실패

- **무한 스테이지**, 시스템 배율 스케일(적 HP·골드 = 기본 × 성장률^s). **블록 = 10스테이지 + 10단위(10·20·30…) 보스**.
- **일반 적도 PC를 약하게 공격**(보스보다 빈도·데미지 현저히 낮음)하지만 항상 클리어. **보스가 치명적** — PC HP 0 시 **몇 스테이지 소폭 후퇴**(`DEATH_SETBACK`, 현재 3 — 블록 첫이 바닥선. 골드·강화 유지, HP 풀충전). **게임오버(영구 종료) 없음.** 상세 [[스테이지 시스템 정리본]] §5.
- **HP 회복 수단**: ①풀충전(보스 진입·사망 재시작 시), ②**체력 재생(hp_regen)** — 블록 내 진행 중 초당 자동회복(2026-06-11 신설). hp_regen은 **"찔끔 유지형"**으로, 일반몹의 찔끔 피해만 상쇄하고 그를 초과하는 큰 피해·연타는 여전히 누적된다(**보스전 중에도 작동하지만** 회복이 작아 보스 순간딜을 상쇄하지 못함 → 무한생존 없음). 따라서 **HP 풀(hp 강화 트랙) 성장이 보스 생존의 진짜 축**으로 유지되고, 블록 내 누적 압박(=HP 업글 동기)도 보존된다. 상세는 [[전투 시스템 정리본]] / [[강화 시스템 정리본]].
- 일반 스테이지 잡몹은 같은 종류 여러 마리 무리(웨이브)로 등장해 앞에서부터 차례로 상대하며, 무리 전멸 시 진행도 1(맨 앞 한 마리만 PC 공격). 상세 [[스테이지 시스템 정리본]].
- 성장 벽(이중): 잡몹 처치 느려짐(soft) + 보스 진행 차단(hard).
- → 상세(스케일 공식·보스·사망/재시작·오프라인 정산·성장 벽)는 **[[스테이지 시스템 정리본]]**.
- → 수치 튜닝 전 성장축 역할·전투 시간·경제 기준은 **[[밸런스 초안]]**.

## 10. 보류 항목 / 로드맵

- **랭킹**: 비활성(추후 완전 제거 검토). 방치형에서 랭킹 의미가 적음.
- **환생(프레스티지)**: 보류. 핵심 루프 안정 후 도입 검토(테마: "복권 1등 → 더 좋은 복권으로 갈아타기").
- **장비(무기·방어구)**: 시스템 본체 **구현 완료** — 5등급(common~mythic, 등급=수치 차등) 곱 보너스(무기 = 공격력 · 방어구 = 최대HP), 다이아 가챠(상점 소환 1회/11연차) + 골드 강화 + 합성(같은 종류·등급 N=4 → 상위) + 종류별 1슬롯. [[장비 시스템 정리본]]. ⏸ 천장·다이아 획득처·정식 카탈로그(현재 더미) 미정.
- **유물(슬롯 빌드)**: 시스템 본체 **구현 진행/반영됨** — 5슬롯, 효과별 최고 등급 1개 유지, 중복 자동 가루 환급, 상점 > 소환 > 유물(가루) 경로. 효과·획득 리듬·수치 상세는 [[족보 스킬 시스템 정리본]] 참조.
- **BM**: ⏸ 자동긁기 최대속도 맛보기 → 광고 N분 버프 → 광고제거 IAP(방치형 BM 루프). HTML5 광고·결제 제공자는 미정. 상세 [[BM 시스템 정리본]].
- **우편함(보상 지급 통로)**: 1차 구현 완료(`mailbox.gd`/`mailbox_panel.gd` + backend `mail_claimed`). 테스트/운영/이벤트 일회성 보상을 수령식으로 전달하는 공용 통로(리텐션과 독립). 상세 [[우편함 시스템 정리본]].
- **퀘스트(메인·일일·반복·이벤트)**: 1차 구현 완료(데이터 주도 카탈로그 `quests_main.yaml`[메인 25종]·`quests_daily.yaml`[일일 7종, 노출 6 — 소환 `exposed=false`] → `quests.gd` + `quest_panel.gd`[일일 전용] + `quest_tracker.gd`[메인 HUD 트래커] + stat 델타 진행도). 목표/진행도/완료/수령을 담당하는 별도 시스템. 일일 퀘스트는 리텐션 효과가 있지만 퀘스트 시스템 소유. ⏸ 반복/이벤트 퀘스트는 미구현. 상세 [[퀘스트 시스템 정리본]].
- **리텐션(출석·복귀·업적 보상 알림)**: ⏸ 기획 초안. 매일 받을 것과 복귀 재진입을 수령식 보상으로 묶되, 우편함·퀘스트와 독립된 책임으로 처리. 상세 [[리텐션 시스템 정리본]].
