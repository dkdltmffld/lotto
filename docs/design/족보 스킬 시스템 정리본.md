## 1. 개요

스크래치 족보 공격을 **발라트로식 '스킬'**(족보별 강화·특화)로 차용한다. 단 **족보 체계는 포커가 아니라 "매칭 그룹"** — **같은 숫자 N개 = 당첨 등급**(실제 스크래치 복권의 "같은 거 N개 맞추면 당첨"과 일치). 위력은 매칭 개수로 결정되고, 매칭 등급별로 강화해 키운다.

> 📌 **4성장축 중 위치 (2026-06-08).** 본 문서 범위 = **족보(매칭 등급 레벨업)** 와 **유물(수평·빌드 재미·비파워)**. 나머지 두 축인 **강화(골드 무한 수직 스탯)** ·**장비(능력치+가챠 = BM 기둥)** 는 **별개 축**으로 본 문서 밖이다. ⚠️ **유물 ≠ 장비**: 유물 = 비파워·빌드 정의(수평 정체성), 장비 = 능력치+BM 직결(수직 파워). 본 문서의 유물 가챠(유물 복권)는 장비 가챠(BM)와 **혼동하지 말 것**.

### 1-1. 결정 사항
- ✅ **(2026-06-08 확정) 매칭 그룹**: 같은 숫자 N개(=max-count) = 등급. 페어/트리플/…/나인. **포커(클래식 사다리)·슬롯(라인) 모두 폐기** — 포커는 무늬·9칸에 안 맞고(저족보 거의 안 뜸), 라인은 슬롯머신 느낌이라 복권 정체성·심의에서 멀어짐. 매칭이 복권 정체성에 가장 충실.
- ✅ **포커식 구분 족보(투페어·풀하우스 등)는 추후 "유물로 족보 확장"**: 기본은 단순 매칭(max-count), 별도 구분 등급/콤보는 유물이 해금·확장하는 형식(→§5-2).
- ✅ **나인 잭팟 = 지금 그대로 유지**: count 9(전부 동일)=잭팟. 현행 동작·컷인·튜토리얼 강제잭팟 유지.
- ✅ **(2026-06-10 확정) 유물 중심 — per-grade 족보 강화 폐기**: 족보 성장/특화는 **유물이 전담**한다. **별도의 "족보별 레벨업" 강화 시스템(구 §5-1)은 만들지 않는다.** 강화(골드)는 **균일 배율(현행 `card_mult`)만** 유지 = 수직 노브레이너 sink. 족보 커스텀(분포·족보확장·와일드·특정족보 보너스)은 **전부 유물**. 근거: ①멀티플라이어 수프 회피(균일 배율 1겹 + 유물 빌드 = 2축 선명) ②점진적 복잡도(초반 단순 배율→유물 들어오며 깊이 개방, 방치형 온보딩에 적합) ③레퍼런스(발라트로)도 깊이는 조커=유물에서. ⚠️ **조건(안 얕으려면)**: 유물 효과축이 충분히 다양(확보됨, §5-2) + **초반 유물 1~2개 일찍 지급**(빌드 체감, §5-4 리듬) + 갈아끼우기 자유(슬롯제, §5-3). 부족하면 나중에 per-grade 추가(되돌리기 쉬운 방향).
- ✅ **핵심 플레이어 선택 = 빌드 (전적으로 유물 기반)**: 저등급 주력 vs 고등급/잭팟 주력 = **어떤 유물을 끼우느냐**로 결정. →§4
- ⏸ **위력 공식(value 포함 여부)**: 현재 `count²×value`(높은 숫자 보너스). "지금 그대로 유지"라 당분간 현행 유지, 순수 count-only(패턴만)로 갈지는 밸런스 때 재검토.

> ⚠️ **큰 함의**: 매칭(count) 기반 유지 → 기존 카운트 기반 코드(컷인 트리거·이펙트 티어·잭팟/고족보 임계·`_skill_hand_count`)가 **그대로 유효**. 초기 우려한 "count→족보등급 리매핑"·분류기 대규모 재작성은 **불필요**. 분류기(구분 족보)는 미래 유물 기능으로 이연.

## 2. 매칭 등급 사다리 (기본 = max-count)

9칸 중 **가장 많이 매칭된 같은 숫자의 개수(N)**가 등급. (= 현행 `HandEvaluator` max-count) 낮→높:

| 등급 | 조건 | 빈도/위력 |
|---|---|---|
| (싱글/노매치) | 전부 다름(≈0.09%, 거의 안 뜸) | — |
| 페어 | 같은 숫자 2개 | 자주·약 |
| 트리플 | 3개 | 중 |
| 포카드 | 4개 | 중상 |
| 파이브~에이트 | 5~8개 | 드묾·강 |
| **나인(잭팟)** | 9개 전부 동일 | **희귀·최강** |

- **판정 = max-count 하나만** (복잡한 매핑 규칙 불필요 — 포커식 "최고 클래식 족보" 판정은 폐기). 단순·legible.
- **잭팟 = 나인(count 9)**, 현행 유지. 튜토리얼 강제잭팟(`set_number_pool([9])`) 그대로 유효.
- **⏩ 유물 확장 여지**: 투페어(2+2)·풀하우스(3+2)·쓰리페어 같은 **2차 구조(보조 그룹)**는 기본 사다리엔 없고, **유물이 해금하면** 그때 추가 등급/보너스로 평가(§5-2). 즉 기본은 "최다 매칭 개수"만 본다.

## 3. 위력 / 족보배율

- **족보배율 = 현행 `count²×value`** (등급=count, count² 지배 + value 소폭 보너스). **per-grade 레벨업 폐기**(2026-06-10)라 등급별 level_scale 없음 — 균일 수직 배율은 강화 `card_mult`가 담당(§5-1), 등급별 차등/보정은 유물이 담당(§5-2).
- ✅ **(2026-06-17) 스킬 = 다타격 연출(쪼개기).** 스킬 버스트를 한 방 큰 숫자 → **족보 count만큼 연타(다다다닥)**로 표현. **타수 = count**, 한 타 = 총딜/타수 → `count²×value` 중 count 한 겹을 "타수"로 시각화한 것이라 **총 데미지·밸런스 불변**. 잭팟=무리 전체 연타. 상세 [[전투 시스템 정리본]] §3-3.
- 순수 패턴만(count-only)로 갈지는 밸런스 때(§1-1 ⏸).
- 전투 공식 유지: 스킬 데미지 = `캐릭터 공격력 × 복권배율(card_mult) × 족보배율`. (→[[전투 시스템 정리본]] §3)
- 배율 곡선 TBD — 9칸이면 저등급이 드무니(§9) 윗단 위주 튜닝.

## 4. 플레이어 선택 = 빌드 ✅(방향)

> "플레이어의 선택이 게임 진행에 어떻게 영향을 끼치는가? → 빌드 정하기."

- **저족보 빌드**: 낮은 족보는 **자주 터지지만 상대적으로 약함**. 꾸준·안정 딜.
- **고족보/잭팟 빌드**: 높은 족보는 **드물게 터지지만 상대적으로 강함**. 한방·폭발.
- 플레이어는 **무엇을 주력으로 할지 선택**한다 = **어떤 유물을 끼우느냐**(2026-06-10: per-grade 강화 폐기 → 빌드 결정권은 전적으로 유물).
- **잭팟 빌드의 뽕맛**: 잭팟 특화 유물 조합 후 이어지는 잭팟 딜링이 짜릿. **의도한 허들(스테이지 벽·보스)을 잭팟으로 운좋게 넘어버리는** 변수도 매력.
- 💡 빌드 선택이 성립하는 이유 = **유물 슬롯 한정**(§5-3)이라 모든 효과를 동시에 못 켬 → 자연히 특화. (강화는 균일이라 빌드 변수 아님 — 누구나 배율만 올림.)

## 5. 강화 구조 ✅ — 균일 강화(현행) + 유물(빌드)

> 2026-06-10: 구 "2레이어(기본 강화 + 유물)"에서 **per-grade 족보 강화를 폐기**. 강화는 균일 한 겹, 빌드 깊이는 유물이 전담.

### 5-1. 균일 배율 강화 (현행 유지 · 새 시스템 없음)
- **현행 `card_mult`(복권 배율) 강화를 그대로 사용** — 모든 족보에 일률 적용되는 수직 배율(골드 sink). (+ `attack` 등 기존 강화 트랙.)
- **족보별 개별 레벨업은 만들지 않는다**(구안 폐기). 강화 레이어엔 빌드 선택이 없다 — 누구나 배율만 올리는 노브레이너 수직 sink.
- 족보 특화·커스텀은 **전부 유물**(§5-2)이 담당.
- 재화 = **골드**(현행). 유물용 재화는 별개(§5-4, 경제 기획).[^dia]

[^dia]: 신규 재화 **'다이아'가 이미 추가됨**(2026-06-08) — 단 **현재 장비 가챠 전용**. 유물용 재화(가루 등)는 여전히 ⏸미정(다이아 전용이 아님, 경제 기획에서 결정).

### 5-2. 유물 (제한적 · 빌드 정의)
유물 효과 = **빌드를 형성·확장**. 후보 종류:
- **① 숫자 분포 조절** ✅(동작 확정 2026-06-10): **저숫자 억제** — 낮은 숫자가 나올 확률을 깎아 풀을 고숫자 쪽으로 → 매칭↑ + value↑ **이중 이득**(잭팟/상위족보 빌드). **등급으로 "확률 조정→숫자 제거" 램프**: 일반=1 확률 −30% / 희귀 −50% / 영웅 −70% / 전설 −90% / **신화=1 완전 제거**(+ 필요시 2 일부 억제). 구현 = `set_number_weights` 하나로 통일(−30%=weight 0.7, 제거=weight 0). **degeneracy 방지**: 완전 제거는 최저 1~2개 숫자까지만(풀이 3개 미만으로 안 줄게). (§6)
- **② 족보 확장 (핵심 — 2026-06-08)**: 기본은 max-count만 보지만, 유물이 **포커식 구분 족보를 해금**한다. 예) "투페어(2+2) 유물" 장착 시 투페어를 별도 등급으로 인정+보너스, "풀하우스(3+2) 유물", "쓰리페어" 등. → 같은 매칭이라도 유물 조합에 따라 평가/배율이 달라지는 **빌드 다양성**의 원천.
  - ✅ **(2026-06-10) 정의 = 그룹 크기 묶음을 포커식으로 랭킹.** 9칸 매칭 그룹들의 크기를 내림차순 나열(예 `[4,3,2]`) → **가장 큰 그룹이 등급을 지배**, 투페어·풀하우스는 **그 아래에서만** 발동(포커에서 포카드가 kicker 무시하는 것과 동일). 랭킹: 나인(9) > 파이브~에이트(5·6·7·8) > **포카드(4)** > **풀하우스(3+2)** > 트리플(3) > **투페어(2+2)** > 페어(2) > 노매치. 즉 **투페어 = 최대 그룹이 2이면서 2짜리 그룹 둘**, **풀하우스 = 최대 3이면서 2짜리 보조**. 큰 그룹(4·5…)이 있으면 이미 그 등급이라 투페어/풀하우스 아님(`3+4`→포카드, `5+4`→파이브). → 투페어/풀하우스 유물 = "최대 그룹 2~3 보드를 한 단계 끌어올리는" **저~중족보 빌드 보강재**. 구현 = 평가기에 "그룹 크기 묶음 포커 랭킹" 판정 함수 추가(유물 장착 시만 보조그룹 평가 ON).
- **④ 와일드카드 셀** ✅(동작 확정 2026-06-10): 카드마다 **1칸을 와일드**로 — 어떤 숫자로도 취급(최대 그룹에 합류) → **매칭 +1**(한 단계 상승). **등급 = 발생 확률**(일반 40% → 신화 100%) — *칸 수가 아니라 확률로* 스케일(2칸이면 잭팟 거의 보장이라 망가짐). **degeneracy 방지**: 여러 개 장착해도 **와일드 칸 상한 2**.
- **⑤ 등급 보정** ✅(동작 확정 2026-06-10): 특정 족보 적중 시 배율 +X%. **저/중/고 3밴드**(저=페어~트리플 / 중=포카드~식스 / 고=세븐~나인) — 유물 수 적고 빌드 명확. 빌드 = 주력 족보 밴드에 보정 쌓기. **등급 = 보정 %**(일반 +20% → 신화 +200%, 수치 ⏸). ⑤=기존 등급 강화 / ②=새 등급 창출(보완).
- ⚠️ **유물 빌드는 무한정이면 안 된다** → 유물에 **제한**(§5-3). (무한 기본강화 = 수직 파워 / 제한 유물 = 수평 정체성)
- ✅ **효과 4종 동작 확정(2026-06-10)** — 위 ①②④⑤ 각 spec. **남은 건 등급별 수치 곡선**(확률·배율·풀 크기)만(밸런스, 구현 중 튜닝).

### 5-3. 유물 제한 ✅ / 획득 ⏸

**제한 = 두 가지 다 둔다 (2026-06-08 결정):**
- **보유 제한**: 소유 가능한 유물 수 자체 제한.
- **장착 슬롯 제한**(발라트로 조커식): 보유분 중 **동시 장착 N개**만 활성. ✅ **(2026-06-10) 슬롯 = 5개**(발라트로식). 초반엔 1~2슬롯만 열고 성장으로 5까지 해금하는 방향 가능(해금 곡선 ⏸).
- → 플레이어는 **원하는 대로 갈아끼우며 빌드 결정**. 두 제한이 함께 "무한정 빌드"를 막는다.
- ⏸ 보유 상한 구체값 미정(슬롯=5 확정).

**획득 주 경로 = 유물 복권 ✅ (2026-06-08 결정).** 게임 정체성(스크래치/복권)과 일치 — 유물도 복권을 긁어 뽑는다. (보조 경로는 추후 추가 가능: 마일스톤 선택·리텐션·드랍 등.)
- 📌 재프레이밍: 보유+슬롯 제한이 밸런스를 잡으므로, 획득은 "적게 주기"보다 **"새 유물 결정을 얼마나 자주·어떤 순간에 안기느냐(리듬)"** 문제다.

### 5-4. 유물 복권 (상세) — ✅ 모델 확정 / ⏸ 수치·획득 리듬

### 7-1. 족보 차등 연출 — 🛠 1차 구현(더미)
족보가 높을수록 연출도 **차등**으로 강해진다(타격감·뽕맛 강화):
- **이펙트 차등**(기존): 매칭 개수별 화면 흔들림·버스트·파편·플래시(`_skill_hand_count`=count 기반, `effects.gd`). **매칭 유지라 그대로 OK**(리매핑 불필요).
- **✅ 고족보 컷인 일러스트 (구현)**: `scripts/cut_in.gd`(`CutIn` 전체화면 오버레이) — 어두운 배경 + 스피드라인 + 일러스트 스케일팝/페이드 + 화이트 플래시, 티어별 강도.
  - **플로우 (화면 멈춤 시퀀스)**: 카드 완성 시 `hand_count >= CUTIN_MIN_COUNT`면 **`game.gd._on_card_completed`가 `get_tree().paused=true`(화면 일시멈춤 — PC·몬스터·자동공격·입력 전부 정지) → 컷인 재생 → `_cut_in.finished` 대기 → 멈춤 해제 → 공격 재생(버스트)**. 즉 **잭팟 → 멈춤+컷인 → 공격 → 정상화** 순서. 컷인 노드는 `PROCESS_MODE_ALWAYS`라 멈춤 중에도 재생(검증됨: 멈춤 중 트윈 동작·finished 발화·정상 해제). pause는 씬 전환에도 유지되므로 await 후 반드시 해제.
  - **튜토리얼 2단계 강제 잭팟에서도 발동**(쇼케이스).
  - **일러스트 = 더미**: 현재 PC idle 스프라이트 + 포트레잇 카드 placeholder. **실제 아트는 `@export illustration` 텍스처 꽂으면 카드 없이 raw 표시**(던파식 아트 블리드).
  - **튜닝 노브**: `game.gd CUTIN_MIN_COUNT`(발동 임계, count 기준 — 매칭 유지라 그대로·현재 5)/`CUTIN_REVEAL_DELAY`(공개 대기·현재 0.4), `cut_in.gd HOLD/FADE_*`(타이밍)/`CUTIN_CENTER_Y`(위치·현재 270), `_TIER_COLORS/_TIER_LABEL`. (구현 후속: 가로 꽉 일러스트·밴드 제거·멈춤 후 깨끗한 스윙·스크래치 공개 후 컷인 등 다듬음 완료.)
  - 검증: 라이브 실행 — 밴드·딤·스피드라인·플래시·"JACKPOT!" 중앙 표시 확인, 런타임 에러 0, 웹빌드 savepack DONE. (position 슬라이드 버그 1건 수정: 앵커 중앙 정렬을 깨서 scale팝+페이드로 교체.)
- ⏸ 세부 미정: 컷인 발동 임계 튜닝, 실제 일러스트 에셋(등급별/공용), 스킵·빈도(방치 피로), 잭팟 전용 특별 컷인.

## 8. 데이터 / 코드

- **기본 분류기 = 현행 `hand_evaluator.gd`(max-count)가 이미 그것** — 매칭 그룹 base는 이미 구현돼 있어 **대규모 재작성 불필요**. (count→족보등급 리매핑도 불필요, §1-1 함의)
- **남은 코드 작업(소): ⏩** ①등급 이름/티어를 데이터화(선택) — `data/src/hands.yaml`(등급 id·이름·base_mult) → `data/hands.json` → `GameData`. ②족보 결과 토스트(`NotificationManager.hand_result`, 구 `HandResultLabel`) 출력을 등급 이름으로(선택). ③유물 "족보 확장"용 훅(유물이 보조그룹 평가를 켜는 진입점) — 유물 구현 시.
- **분류기(구분 족보) 재작성은 유물 확장 단계로 이연** — 그때 max-count 위에 보조그룹(2+2, 3+2 등) 평가를 얹는다.
- 전투 공식·상태머신은 코드 유지(테이블만 데이터화). [[reference_data_pipeline]]

## 9. 파생 고려 (튜닝 전 알아둘 것)
- **9칸이면 저족보가 거의 안 나온다**: 1~9 균등 9칸이면 하이카드≈0.09%, 대부분 페어~풀하우스대. 변별·재미는 상위 족보에 몰림 → 사다리/배율·확률 튜닝 윗단 위주.
- **그래서 §6(풀 좁히기)가 중요**: 유물로 풀을 좁히면 윗단 족보가 흔해져 사다리가 살아남.
- **빌드 성립 = 재화/슬롯 한정**: 무한 강화라도 재화가 한정이라 특화가 강제됨(§4).

## 10. 사용자 아이디어 원문 (raw)

> - **플레이어 선택이 진행에 미치는 영향 = 빌드 정하기.** 낮은 족보는 여러 번 터지지만 약, 높은 족보는 드물지만 강. 무엇을 주력으로 할지 선택. 잭팟 강화 후 잭팟 딜링 뽕맛이 끝내줄 것. 의도한 허들을 잭팟으로 운좋게 넘어버릴 수도.

> - **유물 획득 주 경로 = 유물 복권**(테마 일치). 보조 경로는 추후.
> - **족보 차등 연출** 추가 예정: 이펙트 차등 + **고족보 컷인 일러스트(던파 2차각성 컷인 느낌)**. (적어두고 다른 결정 먼저)
