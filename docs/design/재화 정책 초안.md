# 재화 정책 초안

> ⚠️ **초안.** 이 문서는 골드·다이아·유물 가루의 역할과 경계를 정리한다. 정확한 지급량·가격·확률·BM 구성은 아직 확정하지 않는다.
>
> 상위: [[게임 컨셉 정리본]], [[밸런스 초안]], [[BM 시스템 정리본]], [[장비 시스템 정리본]], [[족보 스킬 시스템 정리본]], [[오프라인·방치 시스템 정리본]], [[리텐션 시스템 정리본]], [[퀘스트 시스템 정리본]].

## 1. 목적

재화는 단순히 "쓸 돈"이 아니라 성장축을 구분하는 장치다.

현재 게임에는 최소 3개 재화가 있다.

| 재화 | 현재 상태 | 핵심 역할 |
|---|---|---|
| **골드** | 구현됨 | 기본 성장, 반복 강화, 장비 강화 |
| **다이아** | 구현됨. 단 획득은 임시 더미(퀘스트/우편함 지급 + 치트) — 정식 인게임 획득 루프·BM 미설계 | 장비 소환, BM 축 |
| **유물 가루** | 구현됨. 중복 환급·**보스 첫 클리어(주 획득처)**·**상점>재화 다이아 구매**(2026-06-17)는 정식 동작(수치 더미). 퀘스트는 임시 더미. **우편 지급은 제거(2026-06-17)**. 천장·정식 공급 곡선 미설계 | 유물 소환, 중복 환급, 유물 천장 후보 |

이 문서의 목적은 각 재화가 서로의 역할을 침범하지 않게 하는 것이다.

## 2. 기본 원칙

1. **골드는 플레이 재화다.**
   - 적 처치·오프라인·리텐션으로 계속 들어온다.
   - 자주 쓰고 자주 부족해야 한다.
   - 강화와 장비 강화의 기본 재료다.

2. **다이아는 장비 소환 재화다.**
   - 장비는 능력치 + 가챠 + BM 기둥이다.
   - 다이아를 강화나 유물에 섞지 않는다.
   - 무료 지급량과 유료/광고 지급량은 추후 BM에서 정한다.

3. **유물 가루는 유물 전용 재화다.**
   - 유물은 빌드 방향을 정하는 축이다.
   - 장비보다 센 수직 BM 재화로 만들지 않는다.
   - 중복 유물의 자동 환급과 유물 소환/천장에 사용한다.

4. **재화 간 교환은 신중하게 본다.**
   - 골드 → 다이아, 다이아 → 골드 같은 직접 교환은 경제를 흐릴 수 있다.
   - 필요하면 이벤트/패키지/리텐션 보상 단위로 제한적으로만 검토한다.

## 3. 골드 정책

### 3-1. 역할

골드는 게임의 기본 순환 재화다.

```
전투/방치/오프라인 → 골드 획득 → 강화/장비 강화 → 더 높은 스테이지 → 더 많은 골드
```

골드는 플레이하면 계속 들어와야 하고, 동시에 늘 부족해야 한다.

### 3-2. 획득처

현재/예정 획득처:

| 획득처 | 상태 | 비고 |
|---|---|---|
| 일반몹 처치 | 구현됨 | 마리당 지급 |
| 보스 처치 | 구현됨 | 보스 배수 적용 |
| 잭팟 보너스 | 구현됨 | 고족보 보상감 |
| 오프라인 정산 | 구현됨 | 저장소 상한 적용 |
| 리텐션/퀘스트 보상 | 설계 | 출석/퀘스트/업적 보상 후보 |

원칙:
- 골드 획득량은 스테이지에 따라 증가한다.
- 고정 골드 보상은 후반에 무의미해진다. 골드를 보상으로 쓸 경우 현재 스테이지 골드 보상에 비례시키는 방향을 검토하되, **퀘스트 기본 보상은 골드가 아니라 다이아**로 본다.
- 골드 수입은 잦지만, 저장은 처치마다 하지 않고 기존 저장 정책을 따른다.

### 3-3. 소비처

현재 소비처:

| 소비처 | 상태 | 역할 |
|---|---|---|
| 강화 | 구현됨 | 캐릭터/복권/저장소 기본 성장 |
| 장비 강화 | 구현됨 | 장비 인스턴스 성장 |

추후 후보:
- 리텐션/퀘스트 관련 재시도 비용
- 일부 편의 기능
- 이벤트성 골드 상점

원칙:
- 골드는 **강화 전용**이 아니라 **기본 성장 전반**의 비용이다.
- 장비 소환에는 쓰지 않는다. 장비 소환은 다이아가 담당한다.
- 유물 소환에는 쓰지 않는다. 유물은 가루가 담당한다.

## 4. 다이아 정책

### 4-1. 역할

다이아는 장비 소환 재화다.

장비는 수직 파워와 BM을 담당하므로, 다이아는 이 축에 집중시킨다.

```
다이아 → 장비 소환 → 장착/합성/강화 → 공격력·HP 곱 보너스
```

### 4-2. 소비처

현재 소비처:

| 소비처 | 상태 | 비고 |
|---|---|---|
| 장비 소환 1회 | 구현됨 | `cost_dia` |
| 장비 소환 11연 | 구현됨 | `cost_dia_11` |

추후 후보:
- 장비 소환 레벨/마일리지
- 패키지 상품
- 광고 보상 대체권

원칙:
- 다이아는 장비 가챠와 연결한다.
- 강화 비용으로 쓰지 않는다.
- 유물 소환 비용으로 쓰지 않는다.
- 유료 재화가 될 가능성이 있으므로 무료 획득처와 유료 획득처를 명확히 나눈다.

### 4-3. 획득처

현재(전부 임시 더미 지급 — 정식 인게임 획득 루프·BM·천장 미설계):
| 획득처 | 상태 | 비고 |
|---|---|---|
| 퀘스트 보상 | 구현됨(임시 더미) | 메인/일일 퀘스트 기본 보상이 다이아(`quests_main.yaml`/`quests_daily.yaml` 데이터 카탈로그, `quests.gd`가 `GameData.table`로 로드). 지급은 동작하나 보상량·획득 곡선은 미설계 |
| 우편함 지급 | 구현됨(임시 더미) | 우편함이 다이아를 지급할 수 있음. 발행/지급량은 미설계 |
| 치트 지급 | 구현됨 | 개발용 |

후보:
| 획득처 | 방향 |
|---|---|
| 일일/주간 출석 보상 | 소량 지급 |
| 업적 | 최초 달성 보상 |
| 광고 보상 | 제한적 지급 |
| 패키지/IAP | BM 핵심 |
| 이벤트 | 운영 보상 |

원칙:
- 초반에 장비 소환을 한 번 경험할 수 있는 지급은 필요하다.
- 무료 다이아는 장비 시스템 학습용과 장기 목표용으로 제한한다.
- 다이아 지급량을 너무 많이 열면 장비 BM과 골드 성장의 경계가 흐려진다.

## 5. 유물 가루 정책

### 5-1. 역할

유물 가루는 유물 전용 재화다.

유물은 장비처럼 수직 파워를 직접 올리는 축이 아니라, 스크래치 족보의 방향을 바꾸는 빌드 축이다. 따라서 가루도 장비 다이아와 분리한다.

```
유물 획득/중복 → 가루 환급 → 유물 소환/천장 → 빌드 갱신
```

### 5-2. 획득처

현재:
| 획득처 | 상태 | 비고 |
|---|---|---|
| **보스 첫 클리어** | **구현됨(주 획득 리듬, 2026-06-17)** | `Balance.boss_dust(stage)`/`backend.grant_boss_dust`(세이브 키 `dust_boss_max`로 첫 클리어만, 재파밍 차단). 지급량(`balance.yaml relic_dust`)은 더미 |
| 중복/하위 유물 자동 환급 | 구현됨 | `BackendService.acquire_relic`. 정식 동작 |
| **상점 > 재화 (다이아 구매)** | **구현됨(2026-06-17, placeholder 결제=다이아)** | `relics.yaml dust_shop{amounts,costs}` → `Relics.dust_shop_pack` → `backend.buy_dust_with_dia`(다이아 차감→가루 지급). 상점 재화 탭(`shop_panel`). 환율 잠정 1:1, 결제 통화는 추후 재검토 |
| 퀘스트 보상 | 구현됨(임시 더미) | 일부 퀘스트의 보조 보상이 가루(`quests_main.yaml`/`quests_daily.yaml` 데이터 카탈로그, `quests.gd`가 `GameData.table`로 로드). 지급은 동작하나 보상량·획득 곡선은 미설계 |
| ~~우편함 지급~~ | **제거(2026-06-17)** | 우편 카탈로그에서 가루 보상 제거(`mailbox.gd` test_reward) — 가루는 보스/상점/중복환급/퀘스트로만. (화이트리스트엔 dust 잔존하나 우편 카탈로그가 안 씀) |
| 치트 지급 | 구현됨 | 개발용 |

후보:
| 획득처 | 방향 |
|---|---|
| 블록 클리어(보스 외) | 보스 첫 클리어는 위 '현재'로 구현됨. 보스 외 블록 단위는 미구현 후보 |
| 업적/리텐션 | 빌드 갱신 보상 |
| 이벤트 | 특정 유물 빌드 유도 |
| 오프라인 보상 | 신중히 검토 |

원칙:
- 유물 가루는 다이아보다 플레이 획득에 가까운 성격이 좋다.
- 유물은 빌드 재미가 핵심이므로, 너무 늦게 열리면 존재감이 약하다.
- 다만 초반부터 랜덤성이 과하면 학습이 어렵다. 초반 고정 지급과 랜덤 전환을 분리해서 본다.

### 5-3. 소비처

현재 소비처:
| 소비처 | 상태 | 비고 |
|---|---|---|
| 유물 소환 1회 | 구현됨 | 상점 > 소환 > 유물 |
| 유물 소환 11연 | 구현됨 | 상점 > 소환 > 유물 |

추후 후보:
| 소비처 | 방향 |
|---|---|
| 등급별 유물 복권 | 특정 등급 보장, 효과 랜덤 |
| 유물 직접 구매 | 효과/등급 지정, 가장 비쌈 |
| 가루 상점 | 천장/선택권 역할 |

원칙:
- 유물 가루는 "운을 통제력으로 바꾸는 재화"로 본다.
- 완전 랜덤 소환이 가장 싸고, 등급 보장/직접 구매는 비싸야 한다.
- 가루가 장비 성장으로 새면 유물 축의 정체성이 흐려진다.

## 6. 재화 간 경계

| 항목 | 골드 | 다이아 | 유물 가루 |
|---|---|---|---|
| 기본 강화 | ✅ | ❌ | ❌ |
| 장비 소환 | ❌ | ✅ | ❌ |
| 장비 강화 | ✅ | ❌ | ❌ |
| 장비 합성 | 재료 장비 | ❌ | ❌ |
| 유물 소환 | ❌ | ❌ | ✅ |
| 유물 중복 처리 | ❌ | ❌ | ✅ |
| 리텐션 보상 | 주력 | 소량 후보 | 후보 |
| BM 직접 연결 | 낮음 | 높음 | 중간/검토 |

정책:
- 골드와 다이아는 서로 직접 교환하지 않는다.
- 다이아와 유물 가루도 기본적으로 분리한다.
- 유물 가루는 유물 내부 순환에 묶어둔다.
- 이벤트 보상에서 여러 재화를 동시에 줄 수는 있지만, 각 재화의 의미는 유지한다.

## 7. 상점 구조와 연결

현재 상점 구조:

| 위치 | 역할 | 재화 |
|---|---|---|
| 상점 > 소환 > 장비 | 무기/방어구 소환 | 다이아 |
| 상점 > 소환 > 유물 | 유물 소환 | 유물 가루 |
| 상점 > 패키지 | 준비 중 | TBD |
| 상점 > 재화 | **유물 가루 구매(2026-06-17)** | 다이아(placeholder, `dust_shop`) |

정책:
- 장비와 유물은 같은 "소환" 카테고리에 있어도 재화와 목적이 다르다.
- 장비 소환은 능력치 성장/BM, 유물 소환은 빌드 재미/통제력이다.
- 패키지/재화 탭을 만들 때 다이아와 유물 가루의 판매/지급 여부는 별도로 검토한다.

## 8. 리텐션 / 퀘스트 보상 연결

리텐션과 퀘스트 보상은 성격을 나눠 본다.

- **출석/복귀**는 접속 유인이라 골드 또는 소량 다이아 후보.
- **퀘스트**는 목표 달성 보상이므로 기본값을 **다이아**로 본다.
- **유물 가루/유물 뽑기권**은 일부 퀘스트·업적·이벤트 보상으로 사용해 유물 빌드 갱신 리듬을 만든다.
- 골드는 스테이지 진행에 따라 가치가 크게 변하므로 퀘스트 기본 보상으로는 부적합하다.

방향:
| 보상 종류 | 기본 재화 | 보조 후보 |
|---|---|---|
| 일일 출석 | 골드 | 소량 다이아/가루 이벤트 |
| 일일 퀘스트 | 다이아 | 유물 가루, 유물 뽑기권 |
| 메인 퀘스트 | 다이아 | 유물 가루, 유물 뽑기권, 고정 유물 |
| 업적 | 성격별 | 최초 업적 일부에 다이아/가루/유물 뽑기권 |
| 이벤트 | 발행 주체 결정 | 다이아/가루/유물 뽑기권 가능 |

원칙:
- 운 기반 목표는 퀘스트에 넣지 않는다. 다이아/유물 가루/유물 뽑기권 보상도 운 목표와 묶지 않는다.
- 수령식 보상은 이산 이벤트이므로 수령 직후 `flush()`한다.

## 9. 오프라인 보상 연결

오프라인 보상은 기본적으로 골드만 지급한다.

이유:
- 오프라인은 반복 접속을 유도하는 보조 수입이다.
- 다이아나 유물 가루가 오프라인으로 계속 쌓이면 상점/소환 리듬이 흐려진다.
- 저장소 업그레이드의 의미는 골드 누적 상한과 연결되어 있다.

검토 후보:
- 광고 시청으로 오프라인 골드 2배
- 이벤트 기간에 가루 소량 추가

정책:
- 기본 오프라인 = 골드.
- 다이아/가루 오프라인 지급은 이벤트성으로만 검토한다.

## 10. BM 관점

BM 축은 크게 둘이다.

1. **다이아 기반 장비 소환**
   - 장비는 직접 파워가 오른다.
   - 확률형 상품으로 볼 가능성이 높다.
   - 확률 표기와 무료 지급 정책이 필요하다.

2. **광고 기반 자동 긁기 버프**
   - 확률형이 아니라 시간제 편의/속도 버프다.
   - kplay 보상형 광고 지원 여부 확인이 필요하다.

유물 가루는 BM 직결 여부를 아직 확정하지 않는다.

원칙:
- 장비 다이아는 BM 기둥으로 본다.
- 유물 가루는 우선 플레이 획득/중복 환급 중심으로 본다.
- 유물까지 강한 유료 BM으로 열면 장비와 역할이 충돌할 수 있다.

## 11. 저장 정책

재화 변경은 기존 `BackendService` 정책을 따른다.

| 상황 | 저장 |
|---|---|
| 골드 처치 수입 | dirty 후 주기 저장 |
| 오프라인 정산 | 지급 후 flush |
| 강화 구매 | 구매 묶음 종료 시 flush |
| 장비 소환 | 결과 반영 후 flush |
| 장비 장착/강화/합성 | 이산 이벤트 flush |
| 유물 소환 | 결과 반영 후 flush |
| 유물 장착/해제 | 이산 이벤트 flush |
| 리텐션 보상 수령 | 수령 후 flush |

원칙:
- 연속 수입은 매번 저장하지 않는다.
- 유저 액션으로 재화를 쓰거나 보상을 수령하는 이산 이벤트는 즉시 저장한다.

## 12. 지금 결정하지 않을 것

초안 단계에서 아래 항목은 확정하지 않는다.

- 다이아 정식 획득량
- 유물 가루 정식 획득량
- 장비/유물 소환 가격 최종값
- 장비/유물 가챠 확률 최종값
- 소환 천장/마일리지
- 패키지/IAP 가격
- 광고 보상량/쿨다운
- 유물 가루 상점 3트랙 가격
- 리텐션 보상 배수
- 퀘스트 다이아 지급량
- 퀘스트 유물 가루/유물 뽑기권 지급량

이 항목들은 [[밸런스 초안]]의 전투 시간·경제 기준과 실제 플레이 로그를 보고 조정한다.

## 13. 최소 검증 질문

재화 관련 결정을 할 때 아래 질문으로 확인한다.

1. 이 재화는 어떤 성장축을 담당하는가?
2. 다른 재화가 이미 맡은 역할을 침범하지 않는가?
3. 획득처와 소비처가 같은 플레이 감각을 만들고 있는가?
4. 무료 지급량이 BM 축을 무너뜨리지 않는가?
5. 유저가 다음에 무엇을 해야 재화를 얻는지 알 수 있는가?
6. 재화가 쌓이기만 하고 쓸 곳이 없는 상태가 아닌가?
7. 재화를 쓰는 순간이 저장 정책상 안전한가?
