## 0. 확정 결정 (한눈에)

- **형태 = B(도전/등반) + C(특수 보스) 혼합.** 별도 재화 던전(골드던전·가루던전 등) **없음**. 등반형이되 재화도 지급.
- **전투 = 현 스크래치+족보 전투 그대로 재활용.** 코어 메커니즘 0 수정, **룰(목표/모디파이어)만** 변형.
- **메인과 별개 진행** — 던전 재화로 메인 성장 가속(역방향 의존 없음: 메인 안 해도 던전 막히고, 던전 안 해도 메인 돈다).
- 진입 = **밴드 패널(층 선택) + 아레나 모드 전환** / 명칭 = **"시련의 탑"**(내비 탭은 "던전") / 해금 = **스테이지 10 클리어 후**(유물과 동일, §7).

> ⚠️ **(2026-06-18 개정) 데일리 던전형으로 전환 — "입장 무제한" 기둥 뒤집힘.** 라이브 플레이 후 사용자 결정으로 아래 구조로 변경(이하 본문 중 "입장 무제한 / 클리어=완료 재입장불가 / 결과=토스트"는 옛 MVP 설명, 데일리 레이어가 덮어씀):
> - **입장권(데일리)**: 일일 무료 N개(잠정 10, 자정 리셋 use-it-or-lose-it). 도전·재도전마다 1개 소모. 0이면 입장 불가. 광고/IAP 충전은 ⏸(광고 SDK 후). `backend.dungeon{tickets,date,auto,auto_init}`·`roll_dungeon_tickets_if_needed`·`consume_dungeon_ticket`.
> - **반복 플레이 + 보상**: 클리어 층 **재도전** 가능. 재도전 보상 = 골드(stage_equiv 스케일)+소량 가루(첫돌파×`repeat_dust_ratio`). 입장권이 안전판이라 무한파밍 아님. 첫 돌파는 여전히 다이아·가루 1회성 마일스톤. `grant_dungeon_repeat`.
> - **정식 결과 화면**: 클리어/실패 모달(층·소요시간·보상카드·다음층/재도전/나가기, 실패 원인). `_show_dungeon_result`.
> - **자동 등반(기본 상시 ON)**: 입장 시 실패/최고층/입장권소진 전까지 자동 진행(클리어→결과모달 없이 토스트+바로 다음 층). **끄기는 설정 패널에만**(던전>자동 등반). `backend.get/set_dungeon_auto`, 기본 ON(구 세이브 `auto_init` 1회 마이그레이션).
> - 수치(입장권10·반복배율1.0·가루비율0.2 등) 전부 잠정. 데이터 = `balance.yaml dungeon`.

## 1. 한 줄 컨셉

> **메인은 켜두면 알아서 오르는 *방치 등반*. 던전은 직접 들어가 그 보스의 *규칙*을 빌드로 풀어야 깨지는 *능동 한 판 도전*.** 같은 복권·족보로, 매 보스마다 다른 룰로 싸우는 이산 보스 사다리.

핵심 반전: **메인 = 방치 / 자유 룰 / 소프트 후퇴 / 무한** ↔ **던전 = 능동 / 룰 게이트 / 하드 클리어 / 셀 수 있는 정복.**

## 2. 구조

```
시련의 탑 = 보스 1체 = 1층 (웨이브·잡몹 없음 → 들어가면 바로 보스)

  MVP 명시 구간 (data/src/dungeon.yaml, 1~10층)  ← 큐레이션된 룰·보상 마일스톤
  무한 꼬리 (11층~)  = ⏸ 2차 확장                  ← 고래용 추격 목표, 가루만

진행 : 순차 게이트. max_cleared+1 층만 도전 가능. 클리어 = ✓완료(재입장 불가). 그 위는 잠금.
입장 : 무제한 = 현재 막힌 층을 깰 때까지 무제한 재시도(스태미나 X).
허들 : "못 깬다"뿐 (전투력 벽 + 빌드 벽). 막히면 메인에서 성장 후 재도전.
실패 : 하드 — 시간초과 / PC 사망 = 그 판 실패 → 입구로(보스 풀피). 진행도 변화 0, 후퇴(DEATH_SETBACK) 없음. 페널티 = 시간뿐.
저장 : dungeon_max_cleared (단일 int). 메인 stage 와 완전 독립.
```

### 2-1. 난이도 = 메인 스테이지 환산 (전투력 벽의 좌표)

각 층 보스의 HP/공격력은 **메인 스테이지 환산값(`stage_equiv`)**으로 기존 `Balance.enemy_hp()` / `boss_attack_damage()`를 **그대로 재사용**(던전 전용 밸런스 곡선 신설 ❌ = 튜닝 면적 최소화). 탑 보스는 `floor_hp_mult`로 더 단단 → **"메인에서 그 스테이지를 깨도 탑의 같은 층은 아직 못 깸"** = 탑이 항상 한 발 앞선 추격 목표.

### 2-2. 층 테이블 (잠정 — 데이터 `data/src/dungeon.yaml`)

> ✅ **(2026-06-18 사용자 요청) 10층 → 30층 + 곡선 완화.** 층당 stage_equiv 점프를 작게(=HP 점프 1.18^step 완만)하고 hp_mult 도 낮춤. 초반 1~4층 일반(파워 체크) → 룰 1개씩 점진 도입 → 10·20·30층 마일스톤에서만 복합. (구 10층은 8→180으로 가팔랐음: 층당 +10~35 = 5~350배 점프.)

| 구간 | stage_equiv | HP 계수(hp_mult) | 룰 |
|---|---|---|---|
| 1~4 (학습) | 4 · 7 · 10 · 13 | ×1.25 | `plain` |
| 5~9 (룰 도입) | 17 ~ 35 (층당 +4~5) | ×1.25 | 5=hand_gate2 / 7=time_limit60 / 9=pc_atk_down0.4 (1개씩) |
| **10 (마일스톤)** | 40 | ×1.5 | hand_gate2 + time_limit70 |
| 11~19 | 45 ~ 97 (층당 +5~7) | ×1.35 | hand_gate3 / time_limit / pc_atk_down 순환, 19=복합 |
| **20 (마일스톤)** | 105 | ×1.6 | hand_gate3 + time_limit60 |
| 21~29 | 113 ~ 184 (층당 +8~10) | ×1.4 | 순환 + 25·28·29 복합 |
| **30 (최종)** | 194 | ×1.8 | hand_gate3 + time_limit60 + pc_atk_down 풀 복합 |

> ⚠️ 수치 전부 잠정. 층당 stage_equiv +3(초반)~+10(후반) = HP 1.6~5배 점프(구 5~350배 대비 완만). **난이도 램프**: 초반 `hand_gate`=페어↑(유물 없이 운으로도 통과=접근성), 고층=트리플↑·복합으로 빌드 강제. ⏸ 무한 꼬리(31층~)는 2차(현재 30층까지 명시). 다이아 보상=1~10층만(맛보기), 가루=전 층.

## 3. 룰 (전투 메커니즘 불변, 룰만)

> **전투 코드 0 수정.** 스크래치 3×3·족보·자동공격·스킬 버스트·다타격·잭팟 AoE 전부 그대로. **승리 목표 변형 + 데미지 게이트** 두 종류로만 표현 — 기존 데미지 파이프라인(`_on_card_completed`의 `result`: count/value/groups/mult)에 곱/필터 1줄로 개입.

### 3-1. 룰 카탈로그 (데이터 `rule.type`)

| type | 효과 | 스크래치/족보 정체성 | 코드 훅 | MVP |
|---|---|---|---|---|
| **`plain`** | 보스 처치 = 승리 | 기본 | 기존 `_on_enemy_died` | ✅ |
| **`hand_gate`** | **스크래치 스킬은 특정 족보 이상만 데미지**(페어/트리플↑). 미달 = 0 + "무효!" 토스트. **기본(자동)공격은 그대로 동작**(2026-06-18 사용자 결정 — 게이트는 스킬에만, 진행 막힘 방지) | 족보를 *운*→*조건*으로 역설, 유물(분포·확장·와일드)이 스킬 버스트 키 | `_on_card_completed`에서 `count < min_count`면 스킬 dmg 0(자동공격 무관) | ✅ |
| **`time_limit`** | N초 안에 못 잡으면 실패(풀피 리셋) | 방치의 정반대 — 능동 throughput(빠른 긁기)이 직접 보상 | `_process` 카운트다운(⚠️ 컷인 pause 중 정지 = 게임시간 기준) | ✅ |
| **`modifier`** | 전장 변형. MVP=`pc_atk_down`(자동공격 약화→스크래치 의존↑) | 빌드를 바꾸게 강제 | 입장 시 1회 적용(계수 멤버) | ✅ (pc_atk_down만) |
| `token_limit` | **스킬 발동 N회 제한**(소진 시 카드 잠금) | 운을 끌어낼 횟수가 유한 — 가장 날카로운 비틀기 | `card_completed` 구독→차감→0이면 `is_locked` 유지 | ⏸2차(고층 1개만) |
| `no_jackpot` | 잭팟 AoE 봉인 → 안정 고족보 강제 | — | modifier 분기 | ⏸2차 |
| `only_number:N` | N 숫자만 데미지 | `set_number_*` 분포 강제 | modifier 분기 | ⏸2차 |

> ⚠️ `token_limit`은 "전 층 강제"가 아니라 **특정 고층 1개 모디파이어로만** 격리(운빨 좌절 리스크를 한 층에 가둠). MVP 제외.

### 3-2. 왜 룰이 메인을 흉내 낼 수 없나 (차별화의 본질)

**메인은 "방치"라 구조적으로 영원히 자유 룰이어야 한다** — 룰을 걸면 방치가 깨진다. **던전은 "능동"이라 룰을 걸 수 있다.** 그래서 `hand_gate`·`only_number`·`time_limit`은 메인이 *원리적으로 절대 가질 수 없는 룰*이고, **같은 전투력 총량이라도 빌드 편향에 따라 막히는 층이 달라진다**(자동공격 빌드 → `pc_atk_down`에서 / 복권·유물 빌드 미흡 → `hand_gate`에서). **메인 = 단일 전투력 벽, 던전 = 룰에 맞는 축의 벽.**

## 4. 보상 / 경제 (무한 파밍 방어)

### 4-1. 첫 돌파 1회성만 (사용자 결정 = 반복 채널 제거)

- **클리어 = "완료" 처리, 재입장 불가** → **반복 보상 채널이 아예 없다.** 던전 보상 = 오직 **층별 첫 돌파 1회성**.
- → **무한 파밍이 구조적으로 불가능**(깬 층은 다시 못 들어가니 반복할 게 없음). 무제한 입장 + 재화 지급을 양립시키는 가장 깔끔한 해법.
- **다이아·가루**를 지급 — 비어 있던 **다이아·가루 획득 루프를 정확히 메움**([[재화 정책 초안]]).
- 구현 = `grant_boss_dust`/`dust_boss_max`와 **동일 패턴 복제**: 단일 int `dungeon_max_cleared` 하나로 "이 층을 처음 깼는가" O(1) 판정 → `floor <= max_cleared`면 0 지급(재파밍 원천 차단).

```gd
# backend_service.gd — grant_boss_dust(:584)의 형제 함수 (예정)
func grant_dungeon_clear(floor: int) -> Dictionary:
    var prev: int = int(get_value("dungeon_max_cleared", 0))
    if floor <= prev:
        return {}                                # ← 무한파밍 방어 핵심
    var dia: float  = DungeonData.clear_dia(floor)
    var dust: float = DungeonData.clear_dust(floor)
    set_value("dungeon_max_cleared", floor)      # 선형 진행이라 단일 int로 충분
    if dia  > 0.0: add_dia(dia)
    if dust > 0.0: add_dust(dust)
    flush()                                      # 이산 이벤트 즉시 영속화
    return {"dia": dia, "dust": dust, "floor": floor}
```

### 4-2. 보상 곡선 (잠정 — 완만 선형, 기하 금지)

가챠 비용이 고정(다이아 100/가루 100)이라 보상도 고정 sink에 맞춰 **완만 선형**(다이아·가루는 골드식 지수 절대 금지). **보상 축 분기**: 룰이 요구하는 축의 재화를 그 층이 준다.
- `hand_gate`/`only_number` 층(유물 요구) → **가루 비중↑**
- `modifier(pc_atk_down)`/관문 층(장비 요구) → **다이아 비중↑**

| 층(룰) | 다이아(1회) | 가루(1회) |
|---|---|---|
| 1~2 (plain) | 30 | 50 |
| 3 (hand_gate) | 30 | 120 |
| 4 (time) | 50 | 80 |
| 5 (pc_atk_down) | 100 | 80 |
| 6~9 (복합/유물) | 40~80 | 120~200 |
| 10 (관문) | 150 | 300 |
| 11~ ⏸2차 (무한) | **0** | 완만 지속(`boss_dust`식) |

> **다이아는 10층까지만**(누적 ~650 ≈ 장비 소환 ~6회 = *맛보기*). 무한 꼬리(11층~, 2차)는 **가루만** → **다이아 인플레를 명시 구간에 가둬** 장비 가챠 BM 보호.

### 4-3. 익스플로잇 방어 (반복 제거로 대부분 자동 해소)

| 익스플로잇 | 방어 |
|---|---|
| 저층 반복으로 다이아·가루 파밍 | **클리어 = 완료(재입장 불가)** → 반복 자체 불가 |
| 방치/접속시간으로 다이아 누적 | 던전 = 능동 + **오프라인 등반 없음** → 다이아는 *시간*이 아니라 *전투력 성장(새 최고층 돌파)*으로만 게이트 |
| 가루→다이아 역환전 | 상점은 다이아→가루 **단방향만**(현 `buy_dust_with_dia`) |
| 세이브 조작 max_cleared 점프 | 클라우드 단일키+압축, 첫 돌파 1회성 → 점프해도 *미래* 보상만 스킵, 추가 지급 0 |

> **핵심 불변식**: "다이아/가루 = 첫 돌파 마일스톤(유한·단조). 반복 없음." 무제한 입장의 허용 비용을 *시간*이 아니라 **전투력 성장**으로만 묶었다.

## 5. 전투력 벽 · 방치/능동

- **입장권/스태미나 0.** 현재 막힌 층은 깰 때까지 무제한 재시도.
- **막히면 진짜 막힘(하드)**: PC HP 0 / `time_limit` 소진 = 그 판 실패 → 입구로(풀피, 진행 0). 다음 층 안 열림. 페널티 = "시간 낭비"뿐 → 부담 없이 재도전.
- **벽을 뚫는 유일한 방법 = 메인에서 성장.** 시간만으론 안 뚫리고 성장만이 뚫는다(키우기 정통 전투력 벽). `hand_gate`/`only_number`는 전투력만으론 안 되고 **유물 빌드**를 요구하는 2차 벽.
- **방치 vs 능동**: 메인 = 방치(오프라인까지). 던전 = **능동**(직접 던전 탭 → 층 선택 → 도전 → 한 판 ~30초~2분). 자동긁기/자동공격은 켜진 채라 손 안 대도 천천히 싸우되, **방치로 알아서 진행되지 않음**(층 선택·재도전이 능동). 메인에 비어 있던 "능동 집중 컨텐츠"를 채움.
- ⚠️ **오프라인 던전 등반 없음**: 탑 다이아·가루는 자는 동안 안 쌓임 = 접속해 도전한 동안만. 오프라인은 메인 골드만(현행).
- **던전 입장 = HP 풀충전 / 전투 중 회복 없음**: 매 도전이 풀피 시작(`_restore_full_hp`). 전투 중엔 강화·장비로 **최대 HP는 늘되 현재 HP는 안 채워짐**(기존 보스전 규칙 `in_boss`, 던전은 매 층이 보스라 적용 — 보스전 중 HP 강화로 풀회복하는 치즈 방지). **(2026-06-18 사용자 결정 C) 던전 전투 중엔 내비 메뉴 탭 자체를 비활성**(강화/장비/유물/상점/던전 전부 음영 + `_on_nav_tab` 차단 + "던전 전투 중에는 사용할 수 없습니다") → 회복 안 되는 강화를 사서 헷갈리는 일 제거. 던전 종료(입구 복귀) 후 정상. (구현: `game._on_nav_tab`·`_update_nav_tab_locks` _mode==DUNGEON 분기.)

## 6. 메인 성장 피드백 루프

```
        메인(골드 그라인드) → 강화·장비·유물 성장
                 │ 전투력 ↑
                 ▼
        던전 새 최고층 돌파  ← "어느 축이 부족한지" 룰이 지목
                 │           (hand_gate 막힘=유물 / pc_atk_down 막힘=장비)
     다이아(장비 가챠) · 가루(유물 가챠)
                 │
        장비·유물 강해짐 → 메인 더 깊이 + 던전 다음 층 (양방향 가속)
```

- 탑 보상(다이아·가루)은 **메인 골드로는 못 사는 성장축**(장비·유물 가챠)을 채움 → 메인 성장 *가속*(제약 4 충족, *대체* 아니라 *보완*).
- 던전이 막히면 **"부족한 축"을 룰이 지목** → 메인 단조 등반에 *방향성 있는 목표* 부여(단순 "더 높이"가 아니라 "이 축을 채워라").
- `only_number`/`hand_gate`가 *유물*을 공략 키로 요구 → **유물 시스템 활용처 공백까지 닫는 자기참조 루프**.

### 8-1. 아키텍처: 별도 씬 ❌ / `game.gd` 경량 모드 분기 ✅

전투 루프가 `_on_card_completed`→`_on_player_attack_completed`→`_skill_multihit`→`_on_enemy_died` **단일 파이프라인**으로 응집돼 있고, 최근 프리징·다타격 버그가 전부 이 핫패스(컷인 pause·다타격·pending 플래그)다. `CombatBase` 선추출은 핫패스를 쪼개 회귀 위험 큼 → **`enum Mode { MAIN, DUNGEON }` + `_mode` 1개, 분기점 딱 3곳**:
1. `_spawn_next` — 던전이면 단일 보스(`stage_equiv`·`floor_hp_mult`·룰 적용), 웨이브 미사용.
2. `_on_enemy_died`(보스 분기) — 던전이면 스테이지 진행 대신 `_dungeon_clear(floor)`.
3. `_on_player_died` — 던전이면 DEATH_SETBACK 대신 `_dungeon_fail()`.
   - 추가 훅: `_on_card_completed`·`_auto_attack`에 `hand_gate` 게이트 1줄, `_process`에 `time_limit` 카운트다운 1블록.
   - `_enter_dungeon(floor)`/`_exit_dungeon()`: 씬 전환 없음 → 세이브·HUD·내비 공유 공짜. ⚠️ 진입/퇴장 시 `_skill_pending`/`_auto_pending`/`_aoe_active`/`_cutin_active`/카드 잠금 명시 리셋 + `_clear_wave()`(이력상 프리징 원인 = 상태 잔재).
   - > 별도 씬은 *2차*(던전 전용 배경/연출) 시 재검토. 1차는 회귀 면적 최소화.
