## 0. 한눈에 (확정 사항)
- **장비 = 능력치 + 가챠 (BM 기둥).** 강화(골드 무한 수직)와 **다른 성장 축** — [[게임 컨셉 정리본]] 4축.
- 장비 안에 **종류 여러 개** 예정. **지금은 무기·방어구**만 정리(악세 등은 추후). **등급·성장·획득·장착 구조는 전 종류 공용**, **종류별로 올려주는 스탯만 다름**:
  - **무기 → 공격력**, **방어구 → 최대 체력**. (둘 다 곱 배율, §3.)
- ✅ **5등급**: 일반 / 희귀 / 영웅 / 전설 / 신화. **등급 = 스탯 수치(배수)만** 결정(치명타·골드 같은 차등 효과 없음).
- ✅ **장비는 스탯을 곱(배율)으로 제공** — 장착 시 해당 스탯 ×(1+보너스).
- ✅ **성장 = 등급 + 개별 강화(레벨).** 같은 등급도 강화로 키움.
- ✅ **상위 등급 획득 = 뽑기 + 합성**(같은 종류·등급 N개 → 상위 1개).
- ✅ **종류별 1슬롯 장착** — 무기 1 + 방어구 1 동시 장착(각 종류 슬롯 1개), 장착한 것의 능력치 적용.

## 1. 전투 연동 (어디에 붙는가)
전투 모델([[전투 시스템 정리본]]): 자동 공격 = `공격력 × AUTO_ATK_COEF`, 스킬 = `공격력 × 복권배율 × 족보배율`. 체력(HP)은 생존력(보스·잡몹 피격을 버팀).

장착 장비는 해당 스탯에 **곱 보너스**를 준다:
```
공격력_최종 = 공격력_강화(골드 트랙) × (1 + 장착무기_보너스)
최대HP_최종 = HP_강화(Upgrades "hp") × (1 + 장착방어구_보너스)
```
- 강화(골드)가 스탯 **베이스**를 무한 가산, 장비는 그 위에 **곱 배율** → 두 축이 곱해져 가챠 파워 체감 큼(BM 기둥).
- **무기 공격력 보너스 = 자동·스킬 두 레이어 모두 반영**, **방어구 체력 보너스 = 최대 HP↑**(보스·잡몹 피격 생존).
- 미장착 시 보너스 0(=×1).
- **방어구 장착/강화/합성으로 최대 HP가 바뀌면 현재 HP도 처리한다**(`game.gd _on_equipment_changed`, 2026-06-15 결정): **보스전이 아니면 상한까지 풀충전**(강화 hp 구매와 동일 — 늘어난 최대치를 현재 HP에 반영해 "최대 HP만 늘고 현재 HP는 안 느는" 비대칭 제거). **보스전 중엔 상한만 갱신**(상한 하향 시 clamp)으로 보스전 회복 금지와 일관.

## 2. 등급 체계 (전 종류 공용) ✅
| 등급 | 키 | 색(잠정) | 가챠 가중치(잠정) | 확률 |
|---|---|---|---|---|
| 일반 | `common` | 회색 `(0.78,0.80,0.84)` | 60 | 60% |
| 희귀 | `rare` | 파랑 `(0.40,0.62,1.00)` | 28 | 28% |
| 영웅 | `epic` | 보라 `(0.74,0.45,0.96)` | 9 | 9% |
| 전설 | `legendary` | 금색 `(1.00,0.80,0.30)` | 2.5 | 2.5% |
| **신화** | `mythic` | 빨강 `(1.00,0.35,0.30)`(신규) | 0.5 | 0.5% |

- 등급이 곧 **스탯 배수 티어**. 상위 등급일수록 큰 점프(아래 §3). 무기·방어구 동일한 등급·색·가중치를 공유.
- 가중치는 **합성 도입**을 전제로 하위 등급 위주(신화는 주로 합성으로). ⏸ 소환 레벨(반복 시 상위 확률↑)은 추후.

## 3. 장비 능력치 (타입별 곱 배율) ✅구조 / ⏸수치
타입별로 **올려주는 스탯만 다르고** 구조·공식은 동일:
| 타입 | 올리는 스탯 | 장착 효과 |
|---|---|---|
| 무기 | **공격력** | 공격력 ×(1+보너스) |
| 방어구 | **최대 체력** | 최대 HP ×(1+보너스) |

- **장착 보너스** = `등급_base × (1 + ENH_PER_LV × 강화레벨)`
- 장착 시 `스탯_최종 = 베이스 × (1 + 보너스)`.

**등급별 base 보너스 (잠정, 공용)** — 장착·강화 0레벨 기준:
| 등급 | base 보너스 | 장착 효과(예) |
|---|---|---|
| 일반 | +0.10 | ×1.10 |
| 희귀 | +0.30 | ×1.30 |
| 영웅 | +0.80 | ×1.80 |
| 전설 | +2.0 | ×3.0 |
| 신화 | +5.0 | ×6.0 |

- ⏸ base 표는 무기·방어구 **공용 시작값**. 공격력↑과 체력↑은 밸런스 성격이 달라(공격=DPS, 체력=생존) 추후 **타입별로 따로 튜닝** 가능.
- ⏸ **개별 장비 스탯 편차**: 같은 등급 장비는 **이름·외형만 다르고 능력치는 동일**(cosmetic)로 시작 — "등급=수치만"에 충실, 설계 단순. (편차 도입은 추후 검토.)
- 따라서 장착 의사결정 = 종류별로 "보유 중 **가장 높은 (등급, 강화레벨)**" 장착. 단순하지만 키우기 표준.

## 4. 성장 ① 개별 강화 (골드 sink) ✅구조 / ⏸수치
- 장비마다 **강화 레벨**(+0, +1, …). 골드(+추후 재료) 소모로 레벨업 → §3 공식의 `강화레벨`↑.
- **`ENH_PER_LV` 잠정 0.10** (레벨당 base의 10% 추가) → +10레벨이면 base×2.
- ⏸ **상한**: 등급별 상한? 공통 상한(예 +20)? / **비용 곡선**: `base_cost[등급] × growth^level`(등급↑일수록 비쌈), 지수 증가.
- 강화는 **장비 단위**(장착 중이 아니어도 강화 가능 — 합성 재료 키우기 등). 무기·방어구 동일 규칙.
- 💡 강화 실패/하락은 없음(단순 가산). 확률형 강화는 유물 축(별도).

## 5. 성장 ② 합성 (등급업) ✅구현 / ⏸수치
- **같은 종류·같은 등급 N개 → 상위 등급 1개** (무기는 무기끼리·방어구는 방어구끼리). **N 잠정 = 4**(레퍼런스 5 — 튜닝).
- 결과 = 상위 등급 카탈로그 중 **무작위 1개**, **강화레벨 0**으로 생성.
- **재료 소모**: 합성에 쓰인 N개는 사라짐. **장착 중인 장비는 재료에서 제외**(보호).
- ✅ **(2026-06-17) "전체 합성" — 한 번에 가능한 모든 합성**: 버튼 1회로 **합성 가능한 모든 장비를 저등급→고등급 cascade**한다. `backend.combine_all_equips(pool)`가 `_combine_one`을 반복한 뒤 디스크 쓰기 반복을 피해 **1회만 flush**한다.
- ✅ **(2026-06-17) 신화(최상위) = 합성 불가 → 돌파/별로 흡수** (§5-1). 중복 신화는 합성 대신 별을 올린다.
- ⏸ 합성 시 강화레벨 승계? (현재안: 승계 없음, 결과는 0레벨 — 단순). 강화 재료 환불 여부도 ⏸.
- 목적: **중복 처리 + 컬렉션 동기 + 가챠 천장 대체**(저등급 양산 → 합성으로 상위).

## 5-1. 성장 ③ 신화 돌파 / 별 (초월) ✅구현 / ⏸수치
- **문제**: 신화는 합성으로 올릴 등급이 없어 중복 신화가 "죽은 무게"가 됨. → **돌파/별**로 흡수해 끝없는 성장축 + 가챠 천장으로 전환(2026-06-17 결정·구현).
- **자동 흡수(클러터 0)**: 같은 종류 신화를 **이미 보유한 상태**에서 신화를 또 얻으면(가챠·합성 결과 모두) → 새 인스턴스를 안 만들고 **보유 중인 그 종류 신화의 별(`stars`) +1**, 중복은 소비. 첫 신화만 일반 인스턴스(`stars=0`). 종류당 신화 1개로 합쳐지고 별이 쌓임(유물 자동 환급과 같은 "쌓임 0" 철학). 개별 신화 아이템은 cosmetic(파워=등급)이라 같은 종류 신화끼리 별 연료로 호환.
- **별 효과**: 장착 보너스 = `base × (1 + per_lv×강화레벨) × (1 + star_bonus_per×별)`. 신화 위 등급 없이도 끝없는 % 성장. (`Gacha.equip_bonus(grade, level, stars)`.)
- **수치**: `equipment.yaml star{bonus_per: 0.20, cap: 0}`(cap 0 = 무제한 — 엔드게임 천장; cap>0이면 상한 도달 시 흡수 안 하고 별도 인스턴스). 1 중복 = 1별. **전부 더미·미튜닝**.
- **세이브**: 신화 인스턴스 dict에 `stars` 키 추가(다른 등급은 없음 — 하위호환, 마이그레이션 불필요·`get("stars",0)`).
- **UI**: 인벤토리 행/장착 라벨에 **"N성"** 표기(★는 번들폰트 미존재로 웹 깨짐 → 한글). 자동이라 버튼 없음.

## 6. 획득 ✅
- **가챠**: 상점 > 소환. **무기 풀 + 방어구 풀** 구현 완료(`pool_order: [weapon, armor]`, 각 등급당 더미 2종). 소환 리스트 2행, 각각 등급 가중 추첨 → 해당 등급 1개·레벨0. 1회/11연차, 비용=다이아. (시스템 = [[BM 시스템 정리본]] §4.)
- **합성**: §5.
- ⏸ **소환 레벨/마일리지**(반복 소환 시 상위 등급 확률↑ = 천장), **다이아 정식 획득처**(현재 치트만) — BM §6 TBD.

## 7. 장착 / 인벤토리 UI ✅구현
`EquipmentPanel`(내비 "장비" 탭, `equipment_panel.gd`)은 **종류 탭 + 장착 슬롯 + 보유 목록 + 강화/합성** 전부 구현(강화/상점 패널과 동일 밴드):
- **종류 탭 = 무기 / 방어구**(헤더, 강화 패널 서브탭과 동일 위치·크기). 선택한 종류만 표시.
- **장착 현황** 라벨 + **합성 버튼**(같은 줄). 장착·강화·합성 변동은 `Events.equipment_changed`(전역 버스)로 game.gd에 통지 → HUD·최대체력 갱신.
- 보유 인스턴스 목록: 행마다 **장착/장착중** 표시 + **강화 버튼**(골드 비용, 아이콘). 정렬 = 등급 → 강화레벨.
- **합성**: **"전체 합성"** 버튼 1회로 **합성 가능한 모든 장비를 한 번에**(저등급→고등급 cascade, `backend.combine_all_equips`). 신화(최상위)는 합성 대신 돌파(별)로 흡수(§5-1). 버튼은 합성 가능 등급이 하나도 없으면 비활성. (선택식 합성 UI는 미도입.)
- **별 표시**: 신화 인스턴스에 **"N성"**(돌파 수, ★ 대신 한글) — 행·장착 라벨에 표기.
- 상점 소환 결과 팝업과 룩 일관(희귀도색 카드).

## 8. 데이터 / 코드 구조 ✅구현(실제 구조)
**세이브 모델** — 구 `equip_owned {id:개수}`(강화레벨·인스턴스·종류 표현 불가)는 인스턴스 모델로 교체 완료. `_migrate`가 아래 스키마 기본값 보장(`equip_seq`=uid 시퀀스 포함):
```
equips:   { weapon: [ {uid, item, level, stars?}, … ], armor: [ … ] }   # 종류별 보유 인스턴스. item=카탈로그 id, grade는 item에서 파생, level=강화레벨, stars=신화 돌파(별, 신화에만)
equipped: { weapon: "<uid>", armor: "<uid>" }                    # 종류별 장착(없으면 "")
```
- ✅ 구 `equip_owned`(가챠 기반작업 더미)는 placeholder라 마이그레이션 없이 드롭(=리셋). `_migrate`가 새 스키마 기본값만 부여 — `equip_owned`는 코드에 없음.

**데이터** `data/src/equipment.yaml`:
- 등급 공용 정의(`grades`: 키·색·가챠 가중치·base 보너스·강화 곡선·상한).
- 종류별 카탈로그(`pools.weapon.catalog` / `pools.armor.catalog`: id → {name, grade}) — 능력치는 등급에서 파생(개별 편차 없음). 풀에 `stat: attack`/`stat: hp` 표기로 곱 적용 대상 지정.
- 합성 N, ENH_PER_LV 등 상수.
- 변환: `tools/build_data.gd` → `data/equipment.json` → `GameData`.

**코드**:
- `scripts/gacha.gd`(`Gacha`) — 등급 추첨·인스턴스 생성(종류별 풀) + 장비 헬퍼(`equip_bonus(grade,level)`, `enhance_cost`, `next_grade`, `combine_n`, `random_item_of_grade`, `item_info`).
- `backend_service.gd` — equips/equipped 세이브 + 장착/강화/합성 API(`add_equip`/`set_equipped`/`enhance_equip`/`combine_equips`/`equipped_bonus`, 이산 이벤트 flush).
- `game.gd` — `_attack_power()`=`Upgrades.value("attack")×(1+equipped_bonus("weapon"))`, `_max_hp()`=`Upgrades.value("hp")×(1+equipped_bonus("armor"))`. `Events.equipment_changed` 구독(`_on_equipment_changed` → 최대체력 재계산·HUD).
- `equipment_panel.gd` — 인스턴스 리스트 + 종류 탭 + 슬롯 + 장착/강화/합성 액션.
- `shop_panel.gd` — 소환(가챠) UI: 무기·방어구 2풀 1회/11연차.
