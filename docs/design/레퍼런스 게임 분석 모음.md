# 레퍼런스 게임 분석 모음 — 콘텐츠 모드 (컨텐츠 확장용)

> 작성 2026-06-19. **컨텐츠 추가**를 위해 레퍼런스 게임들의 **콘텐츠 모드**(메인 방치 진행 바깥에서 별도 보상을 주는 모드)만 게임 단위로 정리하는 문서.
> 레퍼런스 = **슬레이어 키우기(GEAR2)** · **메이플 키우기(MapleStory : Idle RPG, 넥슨·에이블게임즈)**.
> 목적 = **콘텐츠 모드의 설계 구조·패턴 학습 + 우리에게 없는 모드 식별**.
>
> 🚩 **채우는 방식 = 사용자 실플레이가 정답(ground truth).** 웹 조사분은 나무위키 fetch 차단(403)·패치 변동으로 신뢰도가 낮아 **전부 비웠음**(2026-06-19). 아래는 **실플레이로 채워나가는 골격**이다. 각 행은 직접 확인한 것만 적고 **검증 칸**에 표시한다.

## 채우는 법

* 게임을 플레이하며 콘텐츠 모드를 하나씩 발견할 때마다 해당 게임 표에 **한 행씩** 추가한다.
* 각 모드를 5축으로 적는다: **목적·독점 보상** / **입장·반복 제한** / **능동·방치** / **반복성** / **차별화**.
  * **목적·독점 보상** = "이 모드에서만 주는 재화/재료"가 핵심(모드의 존재 이유).
  * **차별화** = 메인 방치 진행과 뭐가 다른가(룰·제약·빌드·협동 등).
* **검증 칸**: 직접 확인했으면 `✅`(가능하면 확인 날짜), 애매하면 `?`, 스크린샷 있으면 `docs/ref/파일명`.
* 모드별 정리가 끝나면 각 게임 **➡️ 우리 적용 후보**에 "우리(복권 키우기) 어디에 매핑 + 적용 난이도"를 적는다.
* 두 게임 다 보고 나면 §3 백로그에서 횡단으로 우선순위를 매긴다.

## 우리 현황 (비교 기준선 — 우리 게임 사실, 정확)

* **메인**: 방치 무한 스테이지(자동 긁기·자동공격) + 보스 게이트(블록=10, 보스마다 PC 위협).
* **콘텐츠 모드 = 던전 "시련의 탑"** (능동 보스 사다리, 보스마다 룰[족보 게이트·시간제한·PC공격↓]) — **데일리화 완료**(일일 입장권·반복 보상·자동 등반). 상세 `던전 시스템 정리본.md`.
* **재화**: 골드(단일 메인 sink) · 다이아(가챠) · 유물 가루(유물). → **재화 분리가 약함**(레퍼런스 대비 핵심 격차 후보).
* **제약(설계 결정)**: 단일 골드 지향(재화 남발 경계) · 랭킹 비활성 정책 · HTML5/kplay 백엔드(실시간·서버랭킹·소셜 부담 큼) · 방치형 정체성(실시간 협동 리스크).
