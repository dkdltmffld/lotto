# 튜토리얼 시스템 정리본

> 첫 시작(저장 데이터 없음) 시 1회 등장하는 **스크립트형 튜토리얼**. 긁기~강화를 실습으로 익힌다. 코어 루프 [[게임 컨셉 정리본]], 전투 [[전투 시스템 정리본]], 저장 [[백엔드 시스템 정리본]].

## 1. 등장 조건

- **저장 데이터가 없는 경우 = 첫 시작**(계정 무관). `BackendService.is_fresh_save`(슬롯 로드 시 데이터가 비었으면 true)로 판단 → `game.gd._ready`에서 `_start_tutorial()`.
- 게스트/인증 **각 슬롯의 첫 시작**에 뜬다(슬롯 분리 [[백엔드 시스템 정리본]] §2). 게임을 조금이라도 하면 저장이 생겨 다음부턴 안 뜸. (별도 "튜토리얼 완료" 플래그 없음)

## 2. 형식

- **상단 안내 배너**(`tutorial_overlay.gd`) — ⚠️ 전체를 덮는 오버레이가 아니라 **입력을 막지 않는 배너**(`MOUSE_FILTER_IGNORE`). 복권 긁기·강화 버튼이 그대로 동작해야 하므로. `set_text(msg)`로 문구만 바꾼다.
- 진행은 "다음 버튼"이 아니라 **게임 액션**(카드 완성·처치·강화 클릭)으로. 상태머신은 `game.gd`(`_tut`: `enum Tut { OFF, SCRATCH, JACKPOT, UPGRADE }`).

## 3. 플로우 (3단계)

| 단계 | 배너 문구 | 동작 / 예외처리 |
|---|---|---|
| **1. 긁기** | "화면 하단 복권을 긁어 적을 공격하세요! 같은 숫자가 많을수록 공격이 강력해집니다." | 적을 **고HP로 스폰**(강화0 최고 한 방=잭팟 데미지 `5×1×729`의 1.5배 ≈ 5500) → **한 방에 안 죽음**(데미지는 정상 적용). 9칸 1회 완성(공격) 시 → 2단계 |
| **2. 잭팟** | "잘 하셨습니다! 한번 더 적을 공격해보세요." | 다음 카드 **강제 잭팟**(`set_number_pool([9])` → 모두 9). 완성 시 잭팟(count 9 ≥ `CUTIN_MIN_COUNT` 5) → **화면 일시멈춤 + 잭팟 컷인 재생**(`cut_in.gd`, `_play_cutin_then_attack`) → 컷인 종료 후 그 적을 **강제 처치**(`take_damage(current_hp)`) → 칭찬. (컷인 상세 [[족보 스킬 시스템 정리본]] §7-1.) |
| (칭찬) | "대단합니다! 정말 높은 숫자예요!" | 1.8초 후 3단계 |
| **3. 강화** | "강화를 통해 더욱 강해지세요!" | **하단 내비 도크의 강화 탭만 음영 해제 + 강조(깜빡임), 나머지 탭은 음영 유지**. 강화 탭을 누르면 → 튜토리얼 종료(강화 패널 열림) |

- 골드: 2단계 처치 골드 + 잭팟 보너스가 들어와 3단계 강화 자금이 됨.
- 종료: 배너·강조 제거, 자동 긁기 복원, `_enter_run`+`_spawn_next`로 정상 게임 재개.

## 4. 예외처리 (튜토리얼 중)

- ⚠️ **강화 외 UI 잠금 (튜토 전체)**: `_set_tutorial_ui_lock`이 **우편·설정·퀘스트 버튼을 비활성**(`disabled`+회색 틴트)하고 **메인 퀘스트 트래커는 숨김**. 치트 버튼은 dev 전용이라 잠그지 않음. 종료 시 복원.
- ⚠️ **내비 도크 탭 단계별 음영/강조** (`_update_nav_tab_locks` — `_nav.set_locked(id, on)`가 버튼을 음영 처리하되 누름은 막지 않음):
	- **1·2단계(SCRATCH/JACKPOT)**: **모든 탭 음영**(아직 아무 메뉴도 못 엶).
	- **3단계(UPGRADE)**: **강화 탭만 음영 해제 + 깜빡임 강조**(`_start_upgrade_blink`가 modulate 소유), 나머지 음영.
	- **종료(OFF)**: 강화/장비/던전/상점 음영 해제. **유물 탭은 스테이지 10 게이트로 계속 음영**([[족보 스킬 시스템 정리본]] §5-4 — 첫 보스 처치 전까지 유물 잠금).
	- 동작 차단은 `_on_nav_tab` 가드가 담당: `_tut != Tut.OFF`면 **UPGRADE 단계의 강화 탭만** 통과(그 전 SCRATCH/JACKPOT엔 강화 탭도 차단 — 조기 패널 오픈 방지). 음영 표시와 동작 차단이 일치.
- ⚠️ **자동 긁기 OFF (1·2단계)**: 직접 긁도록 유도. `_enter_idle`이 `_tut`가 SCRATCH/JACKPOT이면 `auto_rate=0`. (3단계·종료 후 복원)
- ⚠️ **적이 PC를 공격하지 않음 (1·2단계)**: `_on_enemy_reached_position`이 `_tut == Tut.OFF`일 때만 `start_attacking`. (일반몹 공격 [[전투 시스템 정리본]] §2-2는 튜토리얼 후 정상) PC HP바도 튜토리얼 중 숨김.
- **1단계 적 불사**: 데미지 0이 아니라 **HP를 높게**(자연스럽게 안 죽고 체력바는 깎임).
- **2단계 강제 잭팟·강제 처치**: 운에 의존하지 않고 확정 연출.
- 스테이지/통계/일반 스폰: 튜토리얼 처치는 스테이지 진행·`total_kills` 등에서 제외(2단계 분기에서 early return).

## 5. 데이터 / 코드 위치

- **`scripts/tutorial_overlay.gd`**: 상단 배너(`set_text`).
- **`scripts/game.gd`**: `_tut` 상태 + `_start_tutorial`/`_enter_tut_jackpot`/`_on_tut_enemy_killed`/`_enter_tut_upgrade`/`_end_tutorial`, `_tutorial_mob_hp`(고HP 산정), `_set_tutorial_ui_lock`(`_start_tutorial`에서 잠금·`_end_tutorial`에서 복원 — 우편·설정·퀘스트 버튼 비활성 + 퀘스트 트래커 숨김), `_update_nav_tab_locks`(단계별 탭 음영 — `_update_nav_guide_dots`→`_refresh_hud`/잠금 훅에서 호출, 유물 스테이지 10 게이트 포함), 내비 도크 강화 탭 깜빡임(`_start/_stop_upgrade_blink` → `_nav.get_button("upgrade")`). 코어 훅: `_enter_idle`(자동 OFF)·`_spawn_next`(고HP·HP바)·`_on_enemy_reached_position`(공격 OFF)·`_on_player_attack_completed`(단계 전환·강제 처치)·`_on_enemy_died`(2단계 분기)·`_on_nav_tab`(튜토리얼 게이트 — `_tut != Tut.OFF`면 UPGRADE 단계의 `upgrade` 탭만 통과)·`_on_upgrade_pressed`(3단계 종료, 강화 탭 클릭 시 `_end_tutorial`+강화 패널 열림).
- **`scripts/nav_dock.gd`**: `set_locked(id, locked)` — 탭 버튼 음영(modulate, `disabled` 아님 → 누름 통과). `set_red_dot`과 별개 속성.
- **`scripts/backend/backend_service.gd`**: `is_fresh_save`(`_load`에서 raw 데이터 비었으면 true).
- 문구는 `game.gd` 상수(`TUT_MSG_1/2/3`, `TUT_PRAISE`).
