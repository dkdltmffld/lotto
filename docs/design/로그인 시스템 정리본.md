# 로그인 시스템 정리본

> 계정 종류 · 로그인 게이트 · 게스트 제약 · 전환 정책. 결정일 2026-05-29. 백엔드는 [[백엔드 시스템 정리본]] 참조.

## 1. 개요

- 앱 기동 시 **로그인 화면을 1회** 띄운다(게임 진입 전 게이트). 사용자가 계정 종류 3종 중 하나를 선택해야 게임이 시작된다.
- 로그인 유인은 **랭킹** — 인증 계정만 랭킹에 등록된다.
- **로그인 화면(`login.tscn`)은 현재 메인 메뉴 역할을 겸한다** (2026-06-01) — 설정 메뉴의 "메인 메뉴(계정 변경)" 버튼이 이 화면으로 복귀. 별도 메인 메뉴 화면 없음. 추후 명시적 메인 메뉴로 분리할 수 있음. ([[설정 시스템 정리본]])

## 2. 계정 종류 (3종)

| 종류 | 로그인 방식 | 저장 위치 | 랭킹 등록 | 업적 | 기기 간 동기화 |
|---|---|---|---|---|---|
| **구글 계정** | Google OAuth | 클라우드(+로컬 캐시) | ✅ | ✅ | ✅ |
| **kplay 계정** | kplay 로그인 | 클라우드(+로컬 캐시) | ✅ | ✅ | ✅ |
| **게스트** | 없음(바로 진입) | **로컬만** | ❌ (제한) | ✅ | ❌ |

- **구글 / kplay 계정은 로그인 방식만 다르고 실제 동작은 전부 동일하다** → 코드상 동일한 "인증 계정(authenticated)" 경로. 종류는 표시/분석용으로만 보관.
- **게스트**: 업적 해금 등 게임 기능은 동일하나 **랭킹 등록만 제한**. 데이터는 로컬(localStorage / `user://`)에만 저장.

## 3. 로그인 화면

- 노출 시점: **기동 시 1회**(게임 씬 진입 전). 로그아웃 시에도 이 화면으로 복귀.
- 구성(모바일 세로 360×780): **배경 일러스트**(전체 화면) + **캐릭터**(길 위) + **게임 제목 타이포그래피 이미지**(중상단) + 계정 버튼 3개(구글 / kplay / 게스트, **화면 하단**에 세로 스택·큰 터치 버튼) + 상태 라벨.
- **레이아웃**:
  - **배경 = `bg_main.png` 일러스트 (2026-06-12)**. `$Background`(TextureRect, 전체 화면, `expand_mode=1`·`stretch_mode=6`=`KEEP_ASPECT_COVERED`)로 세로 판타지 게이트 일러스트를 화면에 cover. 이미지(9:16)가 화면(9:19.5)보다 가로로 넓어 좌우가 약간 크롭됨. 캔버스는 불투명(`login.gd _ready`에서 `transparent_bg=false` 명시 — 게임 씬에서 켰을 수 있어 복귀 시 끔). 레터박스 여백(캔버스 바깥)은 여전히 웹 페이지 배경 `frame_bg.png`.
  - `$Character`(TextureRect, `bg_character.png` 검사 일러스트, 화면 중앙 길 위 `offset_top=290`~`bottom=650`, `mouse_filter=2`로 클릭 통과). 렌더 순서: 배경 < 캐릭터 < 로고/버튼.
  - `$BottomScrim`(TextureRect, GradientTexture2D 하단 360px 투명→다크 그라데이션) — 밝은 일러스트 위에서 하단 버튼·문구 가독성 확보.
    - ⚠️ **가독성 스킨 (`login.gd _skin_ui()`)**: 버튼=어두운 반투명 패널(`StyleBoxFlat`)+금색 테두리(5상태: normal/hover/pressed/disabled/focus), 상태 라벨=밝은 크림(`Color(0.97,0.94,0.86)`)+그림자. (구 흰 배경용 어두운 `font_color`는 제거됨)
  - ~~(구) 더미 흰 배경 ColorRect (2026-06-04)~~ / ~~투명 캔버스로 frame_bg 비추기 (2026-06-02)~~ → 일러스트 배경으로 교체.
  - `Logo`(TextureRect, 중상단 312×200 영역, `stretch_mode=5`=`KEEP_ASPECT_CENTERED`) — **게임 제목은 텍스트가 아니라 타이포그래피 이미지**. 현재 `assets/ui/title_logo.png`(1536×1024, 1.5:1) 연결. 교체: `Logo.texture` 직접 또는 `login.gd @export title_logo_texture`.
  - `Bottom`(VBoxContainer, 하단 anchor) — StatusLabel + 버튼 3개를 화면 하단으로 배치.
- 동작:
  - **구글 / kplay**: 플랫폼 로그인 요청 → `user-info` 수신(로그인 완료) → 게임 씬 진입. 타임아웃/실패 시 화면 유지.
  - **게스트**: 즉시 게임 씬 진입(로컬 데이터로 시작).
  - ⚠️ **이미 인증된 상태(`is_logged_in`)에서 계정 선택 시(계정 변경)**: 재인증 없이 진입하려면 **선택한 provider로 `BackendService.commit_auth_session(provider)`를 호출**한다 — 이 함수가 ①`account_type` 갱신 + ②인증 슬롯(`'auth'`, 클라우드)으로 전환 + ③그 슬롯 데이터 재로드를 함께 수행해 표기가 바뀌고 게스트→인증 전환 시 데이터가 섞이지 않는다. kplay는 게임 로드 시 `user-info`를 자동 전송해 `is_logged_in`이 먼저 true가 되므로, 이 호출이 없으면 **게스트→구글 등 계정 변경이 반영되지 않고 이전 계정/데이터가 유지됨**(2026-06-04 버그 수정). `_on_provider_login_changed`(자동 user-info)는 `account_type`이 이미 인증(`google`/`kplay`)일 때만 슬롯을 전환하며, 게스트/미선택 상태에서는 건드리지 않는다.

## 4. 명칭 통일 — '랭킹'

- 사용자 대면 명칭과 우리 API는 **'랭킹'으로 통일**(우리 API `show_ranking`).
- 코드: `BackendService.show_ranking()` 등 랭킹 용어 사용. 단, kplay 플랫폼 프로토콜 문자열(`show-leaderboard`/`submit-score`)은 플랫폼 계약이라 그대로 둔다(내부 한정).

## 5. 게스트 제약

- **랭킹 등록 불가**: 게스트 세션에서는 점수 제출(`submit_score`)을 호출하지 않는다(BackendService가 게이트).
- 랭킹 **보기**는 허용한다(가정 — 아래 §8 참조).
- 저장은 로컬 전용. 클라우드 동기화 없음.

## 6. 전환 정책 / 로그아웃 / 계정 탈퇴

- **게스트 → 로그인 계정 직접 전환 불가.** 변경하려면 로그아웃(또는 탈퇴) 후 로그인 화면에서 다시 선택.

### 로그아웃 (`logout()`)
- **로컬(이 기기) 세션/캐시만** 정리 후 로그인 화면 복귀.
- 인증 계정: 클라우드 사본은 남아 **재로그인 시 복원**.
- 게스트: 클라우드가 없으므로 사실상 로컬 데이터 소멸.

### 계정 탈퇴 (`delete_account()`)
- 구글/kplay/게스트 **공통**: 해당 계정의 **로컬 + 서버(클라우드) 데이터 전부 삭제**.
- 탈퇴 후 같은 계정으로 재로그인하면 저장 데이터가 없어 **신규 계정처럼** 시작(자동 성립 — 클라우드 키 삭제 → 다음 로드가 빈 데이터).
- 우리가 지우는 것은 "게임이 그 계정에 저장한 데이터"이며, 구글/kplay 신원(OAuth) 자체는 삭제하지 않는다.
- UI: "계정 탈퇴" 버튼 배치 위치 미정(TBD). ⚠️ 확인(confirm) 없이 즉시 삭제하지 않도록 2단계 확인/다이얼로그 후속 권장.
- 구현: Provider `clear_local()`(로컬만) / `clear_account()`(로컬+서버) 분리. `logout`→clear_local, `delete_account`→clear_account.

## 7. 구현 매핑

- `BackendService`(autoload):
  - 계정 상태: `account_type`(`""`=미선택 / `google` / `kplay` / `guest`), `is_logged_in`(인증 계정만 true).
  - `begin_login(provider)` — `google`/`kplay`. 플랫폼 로그인 요청.
  - `commit_auth_session(provider)` — 이미 플랫폼 인증된 상태에서 인증 계정으로 진입/변경 시 호출. `account_type` 갱신 + 인증 슬롯(`'auth'`, 클라우드) 전환 + 데이터 재로드.
  - `continue_as_guest()` — 게스트 슬롯(`'guest'`, 로컬 전용)으로 전환 후 그 데이터를 로드해 진입(인증 데이터와 분리).
  - `logout()` — 로컬 데이터 삭제 + 상태 초기화 + `logged_out` 시그널.
  - `submit_score(score)` — **게스트면 no-op**(랭킹 등록 제한).
  - `show_ranking()` — 랭킹 표시 (현재 비활성, [[게임 컨셉 정리본]] §11).
- Provider: `clear_local()`(로그아웃 — 로컬만 삭제, 인증 계정 클라우드 사본은 유지) / `clear_account()`(계정 탈퇴 — 로컬+서버 삭제) / `login(provider_hint)`(인증 요청) / `set_slot(slot, cloud_sync)`(계정 종류별 저장 슬롯 분리: `'auth'`=클라우드 동기 / `'guest'`=로컬 전용).
- 씬: `scenes/login.tscn`(+ `login.gd`)을 **메인 씬**으로. 선택 후 `main.tscn`으로 전환.
- 비웹(에디터/데스크탑): 인증 계정 선택 시 즉시 로그인 처리(개발 편의, LocalProvider가 더미 로그인 emit).

## 8. 가정 / 확인 필요

- **구글 vs kplay 구분**: kplay `login-required` 메시지에 provider 지정 필드가 문서화되지 않음. 현재는 힌트로 `provider`를 실어 보내되 동작은 동일 처리. 실제로 버튼별로 다른 OAuth를 띄울 수 있는지 **플랫폼 검증 필요**(안 되면 두 버튼 모두 플랫폼 통합 로그인으로 수렴).
- **게스트 랭킹 보기 허용** 여부 — 등록만 제한, 보기는 허용으로 가정.
- **로그인 화면 매 기동 노출**: 인증 계정이 브라우저에 이미 로그인돼 있으면 플랫폼이 즉시 `user-info`를 줄 수 있음(재선택이 사실상 즉시 통과). 자동 스킵/기억 정책은 추후.
