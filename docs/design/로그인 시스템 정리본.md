# 로그인 시스템 정리본

> 로그인 화면과 로컬 프로필 선택 정책. 최종 갱신 2026-09-01.

## 1. 결정

- 앱 기동 시 `scenes/login.tscn`을 메인 씬으로 노출한다.
- 버튼은 **구글**과 **게스트** 두 개만 두고, 두 버튼 모두 외부 인증 없이 즉시 게임으로 진입한다.
- 구글은 현재 실제 OAuth 계정이 아닌 **구글이라는 이름의 로컬 프로필**이다.
- 두 프로필은 서로 다른 저장 슬롯을 사용해 진행도가 섞이지 않는다.

## 2. 프로필과 저장

| 버튼 | `account_type` | 저장 파일 | 외부 인증 | 기기 간 동기화 |
|---|---|---|---|---|
| 구글 | `google` | `user://save.json` | 없음 | 없음 |
| 게스트 | `guest` | `user://save_guest.json` | 없음 | 없음 |

- 구글 슬롯은 기존 `user://save.json`을 계속 사용해 기존 로컬 진행도를 보존한다.
- HTML5에서 `user://`는 브라우저의 IndexedDB에 저장되므로 브라우저·도메인·기기별로 격리된다.

## 3. 화면 구성

- 배경: `$Background` (`assets/backgrounds/bg_main.png`)
- 캐릭터: `$Character` (`assets/ui/bg_character.png`)
- 제목: `$Logo` (`assets/ui/title_logo.png`)
- 하단 버튼: `$Bottom/GoogleButton`, `$Bottom/GuestButton`
- 상태 문구: `$Bottom/StatusLabel`

버튼을 누르면 두 버튼을 잠그고 `BackendService.continue_as_google()` 또는 `continue_as_guest()`를 `await`한 뒤 `scenes/main.tscn`으로 전환한다.

## 4. 메인 메뉴·로그아웃·삭제

- 로그인 화면은 현재 메인 메뉴를 겸한다.
- **메인 메뉴**: 현재 진행도를 `flush()`하고 로그인 화면로 이동한다.
- **로그아웃**: 현재 진행도를 저장하고 세션만 비운다. 다시 같은 프로필을 누르면 이어서 플레이한다.
- **계정 탈퇴**: 외부 계정 탈퇴가 아니라 **현재 로컬 프로필의 저장 파일 삭제**다. 다른 프로필 데이터는 유지한다.
- 삭제는 되돌릴 수 없으므로 확인 다이얼로그를 유지한다.

## 5. 구현 매핑

- `scripts/login.gd`: 로컬 프로필 선택과 씬 전환
- `scripts/backend/backend_service.gd`: 계정 표기, 슬롯 전환, 세션 초기화
- `scripts/backend/local_provider.gd`: 슬롯별 JSON 로드·저장·삭제
- `scripts/game.gd`, `scripts/settings_panel.gd`: 현재 프로필을 `구글`/`게스트`로 표시

## 6. 후속 확장 주의점

향후 실제 Google OAuth나 클라우드 동기화를 넣으려면 현재 `google` 로컬 슬롯을 어떻게 계정 데이터로 승격할지부터 정해야 한다. 명시적 마이그레이션 없이 두 저장소를 병합하지 않는다.
