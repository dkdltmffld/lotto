## 1. 개요

✅ **2026-06-08 확정 — 성장 4축 분리.** 성장은 **강화 / 장비 / 유물 / 족보** 4축으로 나뉘며, 본 문서는 그중 **강화 = 골드 무한 스탯·수직 비가챠** 축을 다룬다.

- **강화**(본 문서) = 골드 전용 무한 스탯 성장(수직, **비가챠**)
- **장비** = 능력치 + 가챠(다이아) → **BM 기둥**. 별도 기획서 [[장비 시스템 정리본]]
- **유물** = 슬롯 빌드 '재미'(수평·비파워, 기존 '스킬' 대체). 별도 기획서 [[족보 스킬 시스템 정리본]] §5
- **족보** = 매칭 등급 레벨업. [[족보 스킬 시스템 정리본]]

강화 트랙은 **골드 전용**(수직 성장, 비가챠)으로 키운다. 게임에는 별도 재화 **다이아**(장비 가챠용)가 추가됐으나 강화는 다이아를 쓰지 않는다 — **강화 ≠ 가챠**. 전투력이 곱연산이라 한쪽만 올리면 효율이 떨어져 **고루 키우도록** 유도된다.

- **캐릭터** = 베이스 전투력(`attack`, 일반 공격·스킬 공통) + 보스전 생존(`hp`) + 초당 자동회복(`hp_regen`). ⚠️ 자동공격 **속도는 강화 트랙이 아니라 고정값**(`Balance.AUTO_ATK_SPEED`=3.3/초) — 공격속도 강화는 폐지(2026-06-15).
- **복권** = 스킬 폭발력(`card_mult` 배율 + 족보·숫자) + 방치력(`auto_speed` = 스킬 자동발동 주기)
- **저장소** = 오프라인 누적 상한 (압박 해소용 투자)

- **상한 트랙**: `auto_speed`(Lv 12, 방치가 능동을 못 넘게). 컨셉 §8.
- **자동공격 속도는 강화가 아니라 고정값**(2026-06-15). 옛 `attack_speed` 강화 트랙은 **폐지**됐고, 자동공격 속도는 `balance.yaml` `auto_attack.speed`(= 3.3 초당 횟수, 런타임 `Balance.AUTO_ATK_SPEED`)로 고정이다 — 옛 `attack_speed` 강화 max(Lv 25 = 3.3/초)를 모두에게 기본 제공. `game.gd`가 교전 중 `interval = 1/Balance.AUTO_ATK_SPEED` 고정 주기로 `_auto_attack()`을 발동한다([[전투 시스템 정리본]] §4). 자동공격 DPS는 이제 공격력(`attack`)으로만 성장한다.
- **`hp_regen`(체력 재생) 설계 의도 = "찔끔 유지형"**: 일반몹의 찔끔 피해만 상쇄하고, 그를 **초과하는 큰 피해·연타는 여전히 누적**된다. 따라서 **HP 풀(`hp` 트랙) 성장이 보스 생존의 진짜 축**으로 유지되고, 블록 내 '누적 압박(= HP 업글 동기)'도 보존된다. **보스전 중에도 작동**(현행 `in_boss` 게이트 없음 = 의도된 동작으로 확정)하지만, 회복이 작아 보스 순간딜이 회복을 압도 → **무한생존 위험 없음**. ⚠️ 회복량·비용·상한은 더미·미튜닝(§8) — 새 숫자는 §8 참고.
- `*` **`number_range`는 복권 강화 항목이지만 아직 미구현(계획)**. 현재 `scratch_card.gd`의 `number_min`/`number_max`는 1/9 고정(`@export`). 도입 시 레벨에 따라 `number_max`를 올려 높은 숫자(→ 높은 `value` → `count²×value` 배율 폭발)가 나오게 한다. 메커니즘은 [[스크래치 시스템 정리본]] §4·§7.
- 분류(kind): `char`(캐릭터) / `card`(복권) / `util`(저장소).

## 3. 공식

```
value(Lv) = base_val + per_level × Lv      (선형 — 싸고 자주 누르는 결)
cost(Lv)  = base_cost × cost_growth^Lv      (지수 — 점점 비싸짐)
```
전투력 연계 (2레이어, [[전투 시스템 정리본]] §3):
```
일반 공격(자동) ≈ attack(value) × AUTO_ATK_COEF          ← Balance.AUTO_ATK_SPEED 고정 주기마다(속도 강화 폐지)
스크래치 스킬   ≈ attack(value) × card_mult(value) × 족보배율(count²×value)   ← 9칸 완성마다(버스트)
보스전 생존     = hp(value) 로 버티는 시간     ← HP 풀이 보스 생존의 진짜 축
                  + 초당 자동 회복 = hp_regen(value)  ← 찔끔 유지형(일반몹 찔끔 피해만 상쇄, 큰 피해는 누적)
                                                       사망/튜토 제외·HP 가득이면 스킵·보스전 중에도 작동
방치            = 스킬 자동발동 주기 ∝ auto_speed(value), 오프라인 상한 = storage(value)
```

## 4. 경제 (강화 = 골드 전용)

- **강화 트랙은 골드 전용**(수직 성장, **비가챠**). 게임의 별도 재화 **다이아**는 장비 가챠 축이 담당하며 강화는 쓰지 않는다 — **강화 ≠ 가챠**. (장비/다이아 [[장비 시스템 정리본]])
- **골드 획득**: 적 처치 + 잭팟/고족보 보너스 + 오프라인 정산. (스테이지 [[스테이지 시스템 정리본]] §3·§7)
- **쓸 곳**: 위 3트랙이 한정된 골드를 두고 경쟁 → 이 긴장이 키우는 재미. (컨셉 §7)

## 5. 구매 흐름

`Upgrades.buy(id)`:
1. `is_maxed`/골드 부족 체크 (실패 시 false)
2. `spend_gold(cost)` 차감
3. `upg_<id>` 레벨 +1 (`BackendService.set_value` → **메모리 반영 + dirty 표시만**, flush 안 함)

- **flush(디스크 저장)는 구매 묶음이 끝날 때 1회**: 강화 패널이 **버튼에서 손을 뗄 때(`_on_buy_up`)** `BackendService.flush()` 호출.
  - 이유: **롱프레스 연타** 지원 — 버튼을 1초(`RAPID_DELAY`) 이상 꾹 누르면 `0.06초`(`RAPID_INTERVAL`) 간격으로 연속 구매(다라라락). 디스크 쓰기 반복을 피하기 위해 손을 떼 때 1회만 flush한다.
  - 놓쳐도 주기 autosave(15초)·앱 종료 안전망이 저장(저장 정책 [[백엔드 시스템 정리본]] §2).
- 레벨 저장: `BackendService` `"upg_<id>"`. 골드: `BackendService.get_gold/spend_gold`.
- 구매 후 즉시 반영: `game.gd._on_upgrade_purchased`가 `_apply_upgrade_stats`로 **`player_max_hp`(= `Upgrades.value("hp")` × 장착 방어구 보너스) · `scratch_card.auto_rate` · `scratch_card.brush_radius`** 세 가지를 즉시 갱신. 공격력은 다음 공격 계산 시 `_attack_power`(강화 `attack` × 장착 무기 보너스)로 반영.
- **`hp_regen`은 `_apply_upgrade_stats` 경유 없이** `game.gd._process`가 매 프레임 `Upgrades.value("hp_regen")`을 직접 참조해 초당 회복(`player_hp += value × delta`, 일반 진행·HP 미만일 때만). 그래서 구매 즉시 다음 프레임부터 새 회복량이 적용된다.

## 6. 강화 패널 (UI)

- `scripts/upgrade_panel.gd` — 코드로 빌드한 오버레이(**임시 placeholder**, 추후 UI 스프라이트).
- **하단 내비 도크의 "강화" 탭**(`scripts/nav_dock.gd`)으로 연다. (2026-06-05 개편 — 기존 단독 버튼 폐지, [[UI 시스템 정리본]])
- **레이아웃**: 전투·내비를 안 가리고 **스크래치 영역(내비 아래~바닥)만 덮는 하단 시트**. 서브탭(강화/성장/승급, 현재 강화만 동작) + 보유 골드 + 트랙 행 스크롤 + 빨강 닫기.
  - 행 = [아이콘 슬롯: #13 시트 프레임 배경 + 종류색 placeholder] 이름·Lv·Max Lv / 현재값→다음값(초록) / 비용 버튼(또는 MAX). (UI 스킨 [[UI 시스템 정리본]] §3-2)
  - 골드 부족 → 버튼 비활성. 상한 도달 → "MAX".
- **구매 입력**: 탭 = 1회. **1초(`RAPID_DELAY`) 이상 꾹 누르면 0.06초(`RAPID_INTERVAL`) 간격 연타**. flush는 손 뗄 때 1회(§5).
- **리스트 스크롤**: 스크롤바 + **드래그/스와이프**(마우스·터치) 지원(빈 영역 드래그).
- 패널이 열려도 게임은 멈추지 않음(방치 진행 계속). 구매 시 **전역 버스 `Events.upgrade_purchased` 발행** → `game.gd._on_upgrade_purchased`가 HUD/스탯 갱신.
