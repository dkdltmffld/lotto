# 설정 시스템 정리본

> 방치형이라 일시정지는 없다. 우측 상단 **설정 버튼** → 사운드 + 계정 메뉴(로그아웃·계정 변경·계정 탈퇴). 사운드 [[사운드 시스템 정리본]], 계정 동작 상세 [[로그인 시스템 정리본]], 저장 [[백엔드 시스템 정리본]].

## 1. 개요

- 게임이 자동 진행(방치)되므로 **"일시정지"는 의미가 없어 제거**했다. 그 자리(우측 상단)에는 **설정 버튼**을 둔다.
- 설정은 **사운드 + 계정 관련 메뉴**를 담는다(음소거·볼륨 / 로그아웃·계정 변경·계정 탈퇴).
- 설정 패널이 떠 있어도 **게임은 멈추지 않고** 뒤에서 계속 진행된다(방치). 패널이 입력을 가려 그동안 긁기만 막힌다.

## 2. 진입 / 구성

- 우측 상단 `SettingsButton`(설정 아이콘 `assets/ui/icon/icon_settings.png` + #19 배경 스킨 — 텍스트 "설정"에서 아이콘으로 교체됨) → `SettingsPanel` 오버레이 표시.
- 구성: "설정" 타이틀 + **현재 계정 표시** + **사운드 섹션** + 계정 버튼:

### 사운드 섹션 ([[사운드 시스템 정리본]] §4)
- **음소거** 토글(CheckButton) / **배경음**·**효과음** 볼륨 슬라이더(0~1).
- 컨트롤은 autoload `Audio`를 직접 호출 → 즉시 반영·저장. 패널 열 때 `refresh()`가 현재 값으로 동기화.

### 계정 섹션
| 버튼 | 동작 |
|---|---|
| **메인 메뉴 (계정 변경)** | `login.tscn`(계정 선택 화면)로 이동. 진행은 영구 저장이라 폐기 없음. 로그아웃 없이 이동(세션 유지). |
| **로그아웃** | `BackendService.logout()` (로컬 세션만 정리, 클라우드 유지) → `logged_out` → 로그인 화면 |
| **계정 탈퇴** (붉은색) | `BackendService.delete_account()` (로컬+서버 데이터 삭제) → `account_deleted` → 로그인 화면 |
| **닫기** | 패널 닫기 |

- "메인 메뉴 vs 로그아웃": 메인 메뉴는 세션 유지한 채 계정 선택 화면으로(빠른 계정 변경), 로그아웃은 세션을 끊어 재로그인 필요. 둘 다 `login.tscn`으로 가지만 의미가 다름. (`login.tscn`이 메인 메뉴 역할 겸용 — [[로그인 시스템 정리본]])

## 3. 코드 위치

- **`scripts/settings_panel.gd`**: 설정 오버레이(코드 빌드, **임시 placeholder** — 추후 UI 스프라이트). 사운드 섹션(음소거·BGM·SFX) + 계정 섹션. signal `main_menu_pressed`/`logout_pressed`/`delete_account_pressed`/`closed`. 사운드는 `Audio` autoload 직접 호출(시그널 없음).
- **`scripts/audio_manager.gd`** (autoload `Audio`): 볼륨/음소거 API·저장 ([[사운드 시스템 정리본]]).
- **`scripts/game.gd`**: `$TopHUD/SettingsButton`, `_build_settings_panel`/`_on_settings_pressed`/`_on_main_menu_pressed`/`_on_logout_pressed`/`_on_delete_account_pressed`. `logged_out`·`account_deleted` → `_return_to_login`.
