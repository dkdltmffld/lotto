# 사운드 시스템 정리본

> 효과음(SFX)·배경음(BGM) 재생 인프라. **더미 단계 = 인프라/훅만 구축**, 실제 ogg 파일은 나중에 투입(파일을 넣으면 코드 수정 없이 자동 재생). 설정은 [[설정 시스템 정리본]], 저장은 [[백엔드 시스템 정리본]]. 웹 제약은 CLAUDE.md "HTML5 타겟 제약사항".

## 1. 개요 / 설계 원칙

- **autoload `Audio`**(`scripts/audio_manager.gd`)가 모든 사운드를 담당. 코어 코드는 `Audio.play_sfx("key")` / `Audio.play_bgm("key")`만 호출한다.
- **파일 없으면 조용히 skip**: 카탈로그 경로에 파일이 없으면(더미 단계) 에러 없이 무시(없는 경로는 1회만 로그). 그래서 **사운드 파일이 0개여도 게임은 정상 동작**하고, 나중에 ogg를 넣기만 하면 울린다.
- **버스 코드 셋업**: `.tres` 버스 레이아웃에 의존하지 않고 `Audio`가 런타임에 `Master → BGM / SFX` 버스를 만든다(자기완결 — 웹/이식 안전).
- **SFX 풀**(8개 `AudioStreamPlayer` 라운드로빈)로 효과음 겹침 허용(긁기 연타 등).

## 2. 웹(HTML5) 제약 준수

- **포맷 = Ogg Vorbis(.ogg)** 권장. MP3 금지(라이선스/디코딩).
- **autoplay 정책**: 브라우저는 "첫 사용자 제스처" 전 오디오를 막는다. 본 게임은 **로그인 화면 계정 버튼 클릭 → 게임 진입** 흐름이라 BGM 시작(`game.gd._ready`) 시점이 이미 제스처 이후 → 안전.
- **단일 스레드**: `AudioStreamPlayer`는 메인 스레드, 웹 호환(thread_support=false).

## 3. 카탈로그 (key → 경로)

`audio_manager.gd` 상수. 파일은 `assets/audio/sfx|bgm/`에 `key.ogg`로.

### SFX
| key | 트리거 | 호출 위치 |
|---|---|---|
| `scratch` | 칸 한 개 긁힘(완료) | `scratch_card.gd._finish_cell` (수동·자동 공용) |
| `hand` | 카드 완성(족보, 잭팟 외) | `game.gd._on_card_completed` |
| `jackpot` | 잭팟(9칸 동일) | `game.gd._on_card_completed` |
| `attack` | 플레이어 공격 모션 | `game.gd._start_attack_swing` (`_on_card_completed` / 컷인 후 호출되는 스윙 시작 공통 헬퍼) |
| `hit` | 적 타격 | `game.gd._on_player_attack_completed` — 스킬 분기(스크래치 버스트 타격) + 자동 분기(자동 일반 공격 타격). 데미지는 둘 다 attack 모션 종료 시점 적용 |
| `kill` | 적 처치 | `game.gd._on_enemy_died` |
| `boss` | 보스 등장 | `game.gd._spawn_next` (보스 분기) |
| `player_hit` | 플레이어 피격(보스+일반몹) | `game.gd._on_enemy_attacked_player` |
| `player_dead` | 플레이어 사망 | `game.gd._on_player_died` |
| `upgrade` | 강화 구매 성공 | `upgrade_panel.gd._do_buy` + `equipment_panel.gd._do_enhance`(장비 강화 성공) |
| `reward` | 보상 수령(오프라인/소환/리텐션/업적/보스 가루) | `game.gd._settle_offline`(오프라인 보상)·`_on_enemy_died`(보스 첫 클리어 유물 가루, 2026-06-17) + `shop_panel.gd._do_pull`(장비 소환)·`_do_relic_pull`(유물 소환) + `equipment_panel.gd._on_combine_pressed`(합성 성공) + `mailbox_panel.gd`(우편 수령)·`quest_panel.gd`/`quest_tracker.gd`(퀘스트 수령) + `notification_manager.gd`(업적 칩 표시) |
| `button` | UI 버튼 클릭 | `ui_manager.gd.open`/`open_overlay`(내비 탭·설정 등 패널 열기) + `panel_overlay_base.gd._on_close_pressed`(모든 패널 닫기) + `game.gd._on_nav_tab`(준비 중 탭 클릭) + 각 패널 내부 액션(`shop_panel`·`equipment_panel`·`relic_panel`·`mailbox_panel`·`quest_panel` 등) |

### BGM
| key | 트리거 |
|---|---|
| `main` | 게임 진입(`game.gd._ready`) |
| `boss` | 보스전(선택 — 현재 미연결, 필요 시 `_spawn_next`에서 전환) |

## 4. 설정 (볼륨 / 음소거)

- **설정 패널**(`settings_panel.gd`, [[설정 시스템 정리본]])에 **사운드 섹션** 추가: 음소거 토글 + 배경음/효과음 볼륨 슬라이더(0~1).
- 컨트롤은 `Audio.set_muted/set_bgm_volume/set_sfx_volume`를 직접 호출 → 즉시 반영 + 저장. 패널 열 때 `refresh()`가 현재 `Audio` 상태로 동기화(`set_block_signals`로 재진입 방지).
- 볼륨은 버스 `volume_db`(선형→`linear_to_db`, 0이면 -80db), 음소거는 Master 버스 mute.

## 5. 영속화

- `Audio`가 `BackendService` settings dict에 묶어 저장: `audio_master`/`audio_bgm`/`audio_sfx`/`audio_muted`.
- 저장 시점 = 설정 변경 즉시(`flush`, 이산 이벤트). 로드는 `BackendService.save_ready` 이후(`_load_settings`)에 적용.
- autoload 순서: `BackendService` → `Audio`(project.godot). `Audio._ready` 시 백엔드가 아직 로딩 중이면 `save_ready`를 기다렸다 반영.
