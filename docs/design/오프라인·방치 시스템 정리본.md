# 오프라인·방치 시스템 정리본

> 방치 진행 무게중심 · 두 상한 · 오프라인 정산 · 재접속 주기. 상위 컨셉 [[게임 컨셉 정리본]]. 자동 긁기 메커니즘 [[스크래치 시스템 정리본]] §3-2, 저장 트리거 [[백엔드 시스템 정리본]] §2, 저장소·자동속도 강화 [[강화 시스템 정리본]]. 수치는 전부 잠정.

## 1. 무게중심 — 능동 중심, 방치는 보조

- 자동은 **느린 바닥 수입**(이탈 방지·따라잡기용), 진짜 성장은 직접 긁을 때. 단, 방치로도 꾸준히 성장은 된다.
- 즉 "안 만져도 굴러가되, 만지면 훨씬 빠른" 구조.

## 2. 방치 진행 (자동 긁기 + 자동 일반공격)

- 교전 중에는 **일반 공격(자동)**이 고정 주기(`Balance.AUTO_ATK_SPEED`, balance.yaml `auto_attack.speed`=3.3/초)마다 상시 발동(데미지 = 공격력 × `AUTO_ATK_COEF`). 이게 방치의 바닥 DPS다. (공격속도 강화 트랙은 폐지 — 옛 `attack_speed` max값을 모두에게 기본 제공. 자동공격 DPS는 이제 공격력으로만 성장)
- 그와 별개로 입력이 없으면 복권이 느린 속도로 자동 공개 → 9칸 → **스크래치 스킬(버스트)**이 추가로 터짐 → 처치 → 골드. (메커니즘 [[스크래치 시스템 정리본]] §3-2, 전투 2레이어 [[전투 시스템 정리본]] §3)
- 즉 방치 진행 DPS = **상시 자동공격 + 자동 긁기 스킬** 둘의 합이다. (단순화하던 "자동 긁기만으로 처치"는 더 이상 사실 아님)
- **수동 입력 후 2초간 자동 정지** → 손을 뗀 뒤 2초 후 자동 재개.
- 자동 긁기 속도는 복권 성장 축 `auto_speed`(상한 있음, [[강화 시스템 정리본]]).

## 3. 방치를 묶는 두 상한 (성격 다름)

| 상한 | 제한 대상 | 효과 | 조절 |
|---|---|---|---|
| **자동 긁기 속도 상한** | *시간당* 수입 속도(rate) | 방치가 능동보다 항상 느리게 유지 → 능동의 가치 보존 | 강화 `auto_speed` 상한(Lv 12) |
| **오프라인 누적 상한** | *떠난 시간*을 쌓는 한도(금액 기준) | 일정 주기마다 접속 유도 | 강화 `storage` value |

## 4. 오프라인 정산

- 떠난 시점의 **현재 스테이지를 고정 farming**(스테이지 전진 X)으로 누적.
```
gain = min( offline_rate(stage) × 경과초 , 저장소 상한 )
offline_rate(stage) = gold_reward(stage) / EST_SECONDS_PER_MOB
```
- **경과 60초 미만은 미지급.** 경과 시간은 `last_seen`(마지막 저장 시각) 기준 (`BackendService.consume_offline_seconds`).
- 지급 후 화면 상단에 **"오프라인 보상 +N 골드" 토스트 2초** 표시.

## 5. 누적 상한 = 금액 기준 (의도된 압박)

- 성장으로 시간당 수입이 늘면 **고정 금고가 더 빨리 참** → 방치 가능 시간이 점점 줄어듦 → **저장소 업그레이드 압박**. 저장소를 키우면 다시 편안한 주기로 복구된다.
- **밸런스 원칙**: 압박은 주되 좌절은 금물 — [수입 성장 속도] vs [저장소 업글 속도]가 이 게임 페이싱의 심장.

## 6. 재접속 주기

- **길게** 잡는다(튜닝값). 누적 상한(저장소 value)이 사실상 재접속 주기를 결정한다.

## 7. 데이터 / 코드 위치

- **수치 원본**: 오프라인 수치(`EST_SECONDS_PER_MOB`)·저장소 상한 곡선의 **원본은 코드가 아니라 데이터**다 — `data/src/balance.yaml`(`idle.est_seconds_per_mob`)·`data/src/upgrades.yaml`(`storage` 트랙)에서 편집하고, `tools/build_data.gd`로 `data/*.json` 변환 → 런타임은 `balance.gd`/`upgrades.gd`가 `GameData.table()`로 로드한다. **수치 튜닝은 `.gd`가 아니라 `data/src/*.yaml`에서.** (RC1 데이터 주도 전환)
- **`scripts/balance.gd`**: `offline_rate(stage)`, `EST_SECONDS_PER_MOB`(JSON으로 채워지는 static var).
- **`scripts/backend/backend_service.gd`**: `last_seen` 저장(flush·생애주기), `consume_offline_seconds()`.
- **`scripts/game.gd`**: `_settle_offline()`(로드 시 지급 → `NotificationManager.reward()`로 토스트).
- **`scripts/scratch_card.gd`**: 자동 긁기(`auto_rate`, 수동 후 2초 정지 쿨다운).
